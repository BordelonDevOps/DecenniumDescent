# Decennium Descent V7.2 AI Calibration Lab

This workspace contains the complete V7.2 rules repository and one integrated AI testing suite.

## Run

PowerShell:

```powershell
.\playtests\ai-calibration-suite\RUN_PREPARATION.ps1
```

Or any platform:

```bash
python playtests/ai-calibration-suite/tools/run_all_math.py
```

Then open `playtests/ai-calibration-suite/CURSOR_MASTER_ORCHESTRATOR_PROMPT.md` and give its complete contents to Cursor Agent. Cursor must run all Packs 01–20 and return the raw result directory.

## Important

The executable tests can calibrate arithmetic and stress procedures. AI personas can expose exploits and decision problems. Neither replaces an experienced human GM and live players for fun, communication, pacing, and cognitive load.
