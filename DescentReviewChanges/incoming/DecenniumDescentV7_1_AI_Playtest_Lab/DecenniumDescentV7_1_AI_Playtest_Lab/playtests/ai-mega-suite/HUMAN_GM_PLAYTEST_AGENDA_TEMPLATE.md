# Human GM Playtest Agenda Template

Use this only after AI testing narrows the highest-risk questions.

## Session 0

- Explain the core d20 rules.
- Explain each class loop without teaching every edge case.
- Build or distribute four to six characters.
- Record explanation time and questions.

## Session 1 — Tier I expedition

- Surface charter and equipment.
- One Watch of exploration.
- One standard combat.
- One hazard.
- One harvesting decision.
- One cargo-limit decision.
- One controlled retreat or extraction choice.

## Session 2 — Haven

- Quarantine and provenance.
- Appraisal.
- Sponsor shares, taxes, wages, and true profit.
- One faction choice.
- One downtime activity.
- Prepare the next descent.

## Metrics

- Average player turn time.
- GM lookup count and lookup time.
- Rules misunderstood.
- Decisions players considered meaningful.
- Moments players disengaged.
- Whether extraction affected combat choices.
- Whether noncombat roles mattered.
- Whether class mechanics were understandable.
- Whether players could estimate risk.
- Whether the GM could run without inventing major rules.

## Questions AI cannot settle

- Was the session fun?
- Did choices feel emotionally meaningful?
- Did players communicate naturally?
- Was the workload acceptable to a real GM?
- Did the dungeon feel dangerous rather than merely mathematical?
