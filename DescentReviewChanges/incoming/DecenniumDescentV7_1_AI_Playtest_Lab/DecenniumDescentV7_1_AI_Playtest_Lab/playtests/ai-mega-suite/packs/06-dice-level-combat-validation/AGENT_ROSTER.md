# Agent Roster

- **Build Auditor:** Extracts legal builds from canonical sources and freezes them.
- **Rules Judge:** Validates build legality and issues written, scenario-wide rulings.
- **Encounter Curator:** Copies exact public monster records and terrain into fixtures.
- **Director:** Runs only the frozen encounter and published tactics.
- **Dice Recorder:** Generates deterministic rolls and records every die.
- **Metrics Auditor:** Calculates results only from logged dice and state changes.
- **Exploit Auditor:** Watches action slots, actors, cooldowns, control, concentration, and resource loops.
- **17 Player Agents:** One dedicated persona file per class under `agents/players/`.
