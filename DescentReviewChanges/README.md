# DescentReviewChanges

Owner **review queue** of game / product changes only.

## ReviewBible (continuity bible)

**`ReviewBible/`** is the owner-completed curated pack. Continuity agents open and audit against it going forward (see `DecenniumDescent-main/docs/mechanics/CONTINUITY_SOURCE_OF_TRUTH.md`). Do not treat missing archive dumps outside this pack as source of truth.

## Dual-write queue

Agents dual-write real edits from DecenniumDescent-main here, preserving relative paths (e.g. `docs/manuals/foo.md` → `DescentReviewChanges/docs/manuals/foo.md`). Pull this folder periodically to review what changed in the game.

**Not included here:** daily activity logs, agent transcripts, Cursor rules, continuity/process docs, or other internal ops scratch. Those stay in DecenniumDescent-main only.
