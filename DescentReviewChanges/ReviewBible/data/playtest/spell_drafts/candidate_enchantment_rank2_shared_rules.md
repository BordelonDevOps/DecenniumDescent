# Enchantment control integration — exact-review candidate

LOCAL CANDIDATE — NOT ACTIVE. Proposed publication path: docs/mechanics/ENCHANTMENT_CONTROL_INTEGRATION_PLAYTEST.md. These NEW integration rules accompany seven unselected rank-two Enchantment cards. Source conference and authoring clarification establish draftability, not exact manuscript approval. They grant no cosmology interpretation, source deletion, runtime certification or balance approval.

## Ordinary compelled Attack Actions

When an actual compulsion orders an ordinary Attack Action, use the target's native ordinary attack sequence, including inherent Extra Attack and an NPC's native Multiattack if that is actually its ordinary Action. No additional Action/attack is granted. A source expressly limited to one attack retains that limit: Confusing Flash is such an exception. An ordinary attack instruction is not permission to invent an Attack Action or convert another source's single attack into Multiattack.

Spend required ordinary ammunition normally. The command cannot activate consumable magic, special ammunition with a distinct expendable feature, RP/spellcasting, charges, recharge/per-rest abilities or optional finite-resource riders. Actual optional expenditures remain optional and cannot be compelled indirectly by choosing a method which requires them. Where instruction wording leaves the choice open, the target/controller may use a different legal ordinary method. If none satisfies the instruction, that instruction fails without spending a prohibited resource or manufacturing one. Existing source-specific limits and actual absolute prohibitions remain.

## Application IDs and independently scoped components

Each cast has a distinct application ID. Each component retains its own exact source/caster/target, application identity, deadline and actual defense state. Replacing one component never silently replaces another.

For Dire Charm, successfully established Charmed replaces only that caster's previous Dire Charm Charmed relation. Successfully established servant control replaces only the existing Dire Charm servant component across casters. Charmed-only and servant-only casts can therefore coexist. A successful repeat save, expiry or removal clears only still-active components originating from that application; an old application's save cannot remove a replacement component from another cast. Empty applications have no remaining save schedule. Core Charmed from other sources is unaffected. Shared hard-control history never refunds, even if a component is suppressed or replaced before acting.

## Compelled budget arbitration

This NEW rule resolves collisions among actual active mandatory instructions, including Command, Confusing Flash, Illusive Commands, Dire Charm and Crown of Madness. It does not create commands, extend duration, add repeated control to a one-turn source, grant new target permissions or override an explicit source-specific exception.

Record a priority timestamp for each specific instruction:
- Command, Confusing Flash and Illusive Commands: successful establishment of that failed-save instruction.
- Dire Charm and Crown of Madness: issue of that turn's particular valid order, not the age of the underlying spell alone.
- Simultaneous instructions: underlying effect application order, then a stable source/mechanical ID as the neutral tie-break. Record it before resolving choices; do not decide a favorable order after outcomes.

At execution, gather still-active mandatory instructions and consider earlier priority first. A currently impossible/ineligible instruction claims no budget; proceed to the next. Compatible requirements can share one genuine legal execution. A single Action satisfies two instructions only if that same Action actually fulfills both. Once an earlier valid instruction claims an indivisible ordinary Action/interaction, an incompatible later instruction receives no second copy. Movement uses only the actual remaining movement allowance; sequencing instructions cannot reset spent movement or violate an earlier still-maintained posture/restriction.

A losing ongoing instruction is ineffective only for its contested budget/opportunity, not automatically dispelled. Its compatible independent portions may still operate within existing permissions. Its own endpoint, replacement and saves remain. Priority loss never refunds hard-control history. An invalid later order cannot erase an earlier mandate merely by being issued.

Example: Grovel and an Attack Action may both be satisfied if Prone uses only legal movement/posture and the attack remains legal. Two incompatible ordinary Actions cannot both be demanded from one Action budget. This arbitrates actual compelled behavior; it does not make compulsion optional or restore unavailable actions.

## Six-second control cadence outside initiative

This NEW cadence binds Dire Charm and Crown of Madness's ongoing order/end-save procedures. Other sources retain their actual timing unless expressly bound by a further review.

For a target with no existing initiative/control cycle, successful outside-initiative application begins a six-second virtual target cycle: first START immediately after resolution, first END six elapsed seconds later, then repeated six-second cycles. END resolves before the next cycle's START at the same boundary. Maximum duration remains the original absolute60-second deadline; expiry can end the spell before a later opportunity.

EXACT-REVIEW COMPLETION: a target shares one active virtual control cycle and one ordinary behavior budget across concurrent control applications. A new application during an already-open virtual cycle does not replay START or replenish budgets; its specifically allowed current-cycle END save still occurs. Each spell retains its own maximum deadline, components and saves. This treats application during an outside-initiative cycle like application during an existing regular turn, preventing repeated casts from creating extra immediate Actions.

The cycle supplies the bound spells' order opportunities, one ordinary six-second behavior budget where needed, and their repeat saves. It does not refresh encounter Reactions, recharge, resources, limited uses or manufacture extra combat turns. If actual combat order becomes necessary, establish ordinary initiative before any not-yet-committed hostile behavior; a virtual cycle is no permission for an extra pre-initiative attack.

EXACT-REVIEW COMPLETION for entering initiative: map the currently open virtual cycle to the target's first actual regular turn. Carry already received order opportunities and spent ordinary Action/movement/interaction budgets into that turn; do not replay or refill them at its START. The next still-unresolved END save occurs at that actual turn's END. Thereafter use actual regular starts/ends for future triggers. Keep the original absolute duration deadline. Do not replay already resolved virtual events. Existing effects begun in initiative retain their ordinary original virtual-marker rules if they later leave it; this bridge is for these effects first established outside initiative.

Application after an actual regular START grants no order for that already-started turn. A source explicitly permitting an affected current-turn END save still grants that save. Extra turns do not add order opportunities or repeat saves.

## Fixed-zone eligibility history

Calm Emotions and Zone of Truth have fixed spherical centers and require actual exposure/line of effect from that center. Geometric presence behind total cover is not yet eligible exposure. When cover opens around a creature still inside, that moment counts as its first eligible exposure.

Keep one save/acceptance result per creature per spell application:
- Calm Emotions: willing acceptance or the actual WIS save at first eligible exposure.
- Zone of Truth: the actual CHA save at first eligible exposure.
- Success: unaffected by that cast for its remainder, including later entry/cover changes.
- Acceptance/failure: the cast's existing effect is active only while exposed inside its zone; leaving or total cover suppresses it, and restored exposure resumes it without another save.

Acceptance is not a freely toggled dispel choice. Independent zones retain separate casters, concentration, histories and deadlines. Identical restrictions or suppression do not add numerical magnitude. Being unaffected by one zone does not make a creature immune to a different cast.

Calm Emotions suppresses actual Frightened effects, including a newly acquired Frightened source. Create and retain underlying records, ordinary clocks, maintenance and scheduled repeat saves. Once no valid suppressor remains, still-existing effects resume without replaying their original application. A condition which independently expires or is cured while suppressed does not return.

No emotion-themed name automatically disables a class ability. Actual Mooncursed, Momentum Rampage, Divine Fury, Fury of the Host and Beast Empathy source cards have no new emotion-maintenance requirement here. Their real Frightened rider on an affected recipient remains subject to suppression; other printed effects continue.

## Scope and open evidence

The instruction-priority, split-component and zone histories above are authored tabletop procedures, not executed stateful engine implementations. The two marked cadence completions require explicit exact-review approval, especially concurrent outside-initiative applications and the first real turn's carried budget. Human testing remains necessary for multiple-attack compulsion, long control without concentration, fear suppression and the unchanged Zone of Truth class-price discrepancy.
