# Data-only state and operation contract

Every case contains an initial state, full before/after states for every event, a final state, and complete forward/inverse root test/replace operations. No operation has been applied to canonical data or a game runtime. SHA-256 over a state uses UTF-8 JSON, sorted keys, no insignificant whitespace, unescaped Unicode and no NaN/Infinity. Arrays retain order. File/member hashes use the exact bytes instead.

The complete state is a director-private fixture. Only `publicResults` is a proposed public observation. Private HP, source/guard reasons, saves and application metadata are not new character knowledge. Each actor points to a fully bound authored class profile; all variable resource, action, condition, movement, life, concentration, geometry and custody fields used by that case remain in the full state. Pre-existing paid Ready, Arcane Sight and Antimagic records include exact acquired source, prior cost/time and original expiry. These are declared source-legal initial states, not fabricated campaign history.

`permitted` separates condition and remaining-budget eligibility from turn ownership. `canCommitOrdinaryActionNow` and `canCommitBonusActionNow` additionally require the current real regular slot (or lawful uncontested outside-initiative scene). Reaction also requires an actual trigger. Optional abilities are not automatically invoked. A condition never refills a spent budget. Nonmovement denial is not silently converted into numeric Speed0. Unrelated nonspell properties and original source deadlines remain explicit.

Timestamps are typed seconds/phase/sequence records. Sequence orders separately authored operations within a checkpoint, not extra elapsed time or an extra turn. Same-time expiries are cleared before later voluntary processing. START processing includes real recharge/Ready expiry and any declared ordinary life event. Prism's meaningful ending save follows START processing and precedes voluntary activity. No extra-turn grant, skipped periodic pulse or future action is created by a trace checkpoint.

Held cases are explicitly marked `wholeCaseHeld=true`. They may show conditional interface arithmetic but do not establish the missing defense, transport, form, channel, cure, long-cast provider or campaign identity. Case IDs and holds are linked from every affected disposition. The exact source archive and its extracted members remain inert evidence; supplied scripts are retained byte-exactly and were not executed.
