# Awaken

Status: proposed authored procedure; independent exact acceptance/application remain separate.

KEEP Action,60feet,one Beast or Plant gains sentience and language, Instantaneous. NEW eligible target is one actual living nonsapient Beast/Plant creature with recorded INT3or lower, or one rooted living ordinary plant organism not yet a creature, Small through Large or Tiny, fitting within a20-foot cube and weighing at most1000lb. No detached food, seed lot, dead wood, whole forest/colony counted as one, swarm of distinct organisms, already sapient identity or creature with higher operative INT qualifies. These are explicit NEW cognitive/size limits. The target instinctively resists the offered transformation with WIS unless it genuinely accepts through an existing meaningful communication channel; lack of language alone is not consent. For a plant object use the proposed plant profile's WIS0modifier for this admission save. Success prevents change; failure or genuine consent causes the permanent finite changes below, without ongoing concentration. A Beast/Plant creature retains identity,type,size,body,weight,physical abilities,HP/maxHP,Wounds,injuries,age,resources,real skills and existing movement/attacks; set INT to10, and add the ability to understand and speak ONE actual language the caster knows and chose at commitment. It gains independent reasoning and agency, no spell list, class level, tool proficiency, memories, formula knowledge or automatic affection. Speech is a NEW ordinary audible voice from its own body, at normal speaking volume even if its native mouth is not speech-shaped; actual Silence, inability to speak, Unconscious and other permissions still apply. For a previously noncreature plant, keep its real root/body footprint and weight; NEW typePlant, STR1,DEX1,CON10,INT10,WIS10,CHA10, PB2 with no save/skill proficiencies, all Speeds0, no attacks or manipulatory limbs, ordinary hearing within30feet along actual sound paths and touch through its own living body, no sight or remote root-network senses. It may speak, reason and take an ordinary Action that its actual body can perform, never move its roots, Attack, Help on a task it cannot physically assist, use tools or cast from the new profile alone. Keep known original structural maximum/currentHP as the new HP values without repair; if no prior values existed, assign an undamaged base maximum/currentHP of1/5/10/20 for Tiny/Small/Medium/Large, subtracting any already established actual damage, never refreshing a damaged recorded object. Soft living plant AC10 or woodyAC15; retain an actual better-established native structural AC instead. This newly awakened real plant uses ordinary living-creature life/death, not the HP-only summoned zombie rule. Existing wounds/conditions remain; acquiring cognition is not their cure. It is now an autonomous participant: recruiting it as an actual expedition character consumes an ordinary roster place, while merely remaining a living plant does not create a controllable companion. Existing animal bonds/control sources persist only within their real eligibility/ending terms; newly awakened agency permits refusal of ordinary training/voluntary commands, but does not dispel an independent actual magical compulsion. A genuinely retained companion relation still has its one existing attached phase and budgets; converting to an autonomous recruited character ends that companion phase before assigning an ordinary character turn, never both. The instantaneous improvement cannot be dispelled or suppressed afterward, and no ordinary expiry reverses it; a separate legal later transformation/mental effect can override operative abilities within its actual scope, with this gained identity/language retained in history. Recasting a now-sapient target grants no additional language or resource refresh. Actual death does not create another awakened copy or grant this spell resurrection. Sentience's cosmological/soul meaning remains expressly unreviewed.
