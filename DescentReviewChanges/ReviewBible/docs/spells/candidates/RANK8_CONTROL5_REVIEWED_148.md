# Rank8 Control5 — director-accepted manuscript, unapplied

Input live authority:695 applied /153 pending /0 accepted-unapplied. Canonical files are unchanged. This decision accepts only the five procedures below with every stated hold retained; application remains a separate user action.

## frozen-time-prism

Accepted=true; applied=false. Holds: RC8-H01, RC8-H02, RC8-H03, RC8-H06, RC8-H07, RC8-H08, RC8-H09, RC8-H10.

**scope**

NEW Control5 local authorship only. Exactly frozen-time-prism, paralyzing-presence, power-word-stun, mental-collapse and reality-rewrite. Every other identity and all accepted interfaces remain unchanged. These are video-game authored procedures, not executed game rules. Exact native cards, original questions, historical alternatives and all source files remain evidence; a title or comparison grants no acquisition.

**access**

KEEP every native classAccess row: rank 8, base 21 RP, minimum class level 15. Prism: Druid/Mage/Wizard Conjuration. Other four: Wizard only, Enchantment except Reality Rewrite Illusion. Actual class repertoire acquisition and preparation are required. All five use Action, 120 feet, V/S/F. V is audible speech; S needs a usable free hand or an exact exception; F is the actual class focus. No costly/consumed material is added. No generic upcast, scaling, extra action or additional rank/access is granted. All five are NEW non-concentration ordinary casts; a lawful Ready preparation still uses concentration until release under the accepted Ready interface.

**commitment**

Preflight actual legal Action, components, acquired/prepared access, known target predicates, range/line of effect and available final RP. An empty/known-illegal single-target choice does not commit. Presence instead declares its own real caster-origin activation and may legally resolve with zero qualifying observers; it supplies no free eligibility probe. Hidden HP, defenses, actual enemy identity or private eligibility are resolved after a legal commitment without a free diagnostic. Pay the real class price, modifiers, Dissonance surcharge, Action and real costs; apply cadence and any actual concentration transition; then open the Counterspell window. A failed save gate, hidden ineligibility, suppression, loss of target or counter refunds nothing. Revalidate living finite identity, range, line of effect and required perception at resolution. Each cast has one immutable ID, actual source character/class/rank, payment history, original target declaration and effect roots. A spell source cannot be replaced with a same-named class card. Wizard first prepared family protects BASE Dissonance only; repeats preserve real Refrain and surcharges. Accepted Counterspell/Ready/class hooks retain their exact ranks and costs.

**geometry**

NEW Control5 metric: shortest Euclidean distance between actual occupied body footprints, in feet, in one actual shared spatial frame; <=120 is included. Select an actual exposed point on the target body with a clear line of effect from an actual exposed caster body point. Solid total cover blocks. This is a spell-local three-dimensional measurement, not a global grid amendment. No center placement, remote viewpoint, planar shortcut, assumed huge body or identity inferred from an image is granted. Single-target spells require the caster to perceive that actual creature under its genuine senses. Presence expressly uses the snapshot rule in its procedure. Unsupported body/sense/physical facts remain holds. Cases use declared ground bodies/coordinates and unobstructed ordinary sight unless explicitly qualified.

**saves**

Use actual casting-class DC 8+PB+casting ability modifier plus actual applicable modifiers, including Wizard School Mastery only for the chosen school. WIS saving throws are ordinary binary saves, not fixed-DC task degrees; no universal natural-20 save rule or half-effect is imported. No voluntary save failure is granted. Record raw dice, modifiers, result and DC privately as permitted; do not reveal hidden stats. Actual defenses use their printed scope. Creature type alone is not blanket mental immunity. Exact incoming/output antimagic rules remain applicable.

**hardAdmission**

KEEP the shared source-character/target/encounter hard-denial history. Paralyzed and Stunned are the actual named conditions. If an attempted condition would impose Incapacitated, a previously spent guard prevents that entire new Paralyzed/Stunned condition, with no movement-only substitute. A lawful established hard component spends history once, even if later cured, suppressed, ended or replaced. Independently printed Reality Rewrite experience is separate from Stunned. Named parent immunity prevents that parent. Immunity only to inherited Incapacitated prevents that component, not the other actual parent consequences; when no whole-Action denial can establish, that partial parent does not spend hard history. Initial prevention leaves no banked condition or missing component. Later suppression retains only components actually established, their clocks and the already-spent history. Resuming an established component is not a new admission and does not replay an old concentration loss or other completed one-time consequence. If resumed Incapacitated now makes a genuinely NEW concentration effect unlawful, end that currently held effect under the existing concentration rule; this is not restoration or a replay of the old effect. A suppressed source must still be unexpired and attached to the same live identity.

**conditions**

KEEP Paralyzed: Incapacitated, cannot move/speak, automatic STR/DEX save failures, attacks against have advantage, and an attack that actually hits from within 5 feet is critical. KEEP Stunned: Incapacitated, cannot move, automatic STR/DEX save failures, attacks against have advantage, speech only faltering; no automatic adjacent critical. Incapacitated denies Actions/Bonus Actions/Reactions and ends concentration when it actually establishes. It does not by itself set Speed to zero. Current budgets remain separately recorded; ending a restriction never restores previously spent budgets or ended concentration. Neither parent adds unconsciousness, Prone, dropped items, damage, lost memories or death.

**time**

KEEP typed (seconds,phase) deadlines, never floating .9 substitutes. Absolute expiries phase 0; end triggers phase 10; hostile-round expiry at target regular END phase 20; next slot phase 30. A one-round hostile application expires at the first FUTURE target regular END, excluding the end of a target turn already underway at application. Additional explicit duration rounds count additional future regular ends. A hostile effect does not become a self-buff clock merely by targeting the caster. Outside initiative use application+6 seconds per round, absolute phase 0, only when a cast can lawfully resolve outside initiative; establish ordinary initiative before contested hostile action. Preserve original virtual marker/absolute deadline through order changes, absence, planar changes and mode changes. Extra turns/Actions do not advance these clocks. Mental Collapse uses a base60 elapsed seconds phase0, not ten extra turns; record an actual qualifying class duration modifier separately. No source claims to pause poison, damage, death saves, recovery, concentration, source expiry, custody or prior resource history.

**overlap**

NEW Control5 ownership: every committed cast is distinct. For Prism only, same source-character/target/exact profile uses accepted Speed-control refresh: retain one record and the later lawful deadline, preserve earliest established component identity and spent movement, and add the new cast provenance; no shortening or stacking. Different owners remain independent. Mental Collapse, Presence, Word and Rewrite keep independent cast/application records; same-named restrictions do not add numeric penalties or duplicate condition consequences. New hard applications check the same spent guard. Removing one application does not remove another. Caster death/absence alone does not end these non-concentration applications; target death or terminal identity end removes them without reviving a body or rewinding completed consequences.

**suppressionAndEnd**

KEEP initial prevention distinct from suppression of an established application. No initial prevented payload remains to activate on field exit. Later suppression does not pause clocks or refund hard admission. Missed saves/opportunities are lost, never banked/replayed. Resume only established components before their original deadline, without repeating instant consequences or resource effects. A real cure or dispel removes only its actual covered source/component. None of these titles assigns a Curse, cold/elemental classification, Frozen, Root, disease, object durability or arbitrary dispel tier. These ordinary ongoing rank-8 spell applications can be addressed by a genuinely acquired dispel under that dispel's exact check/range/cost. Wizard class Dispel Magic is rank 3, 3 RP, 60 feet, recharge 2; against rank 8 it checks INT+PB vs18. It is not Greater Dispel. Missing acquisition, perception or a specific cure/defense profile remains held.

**information**

Keep director/private eligibility, save facts, source identities, HP and defense reasons separate from permitted public outcomes. A failed cast does not report exact HP, secret immunity, alignment, intended allegiance or an unobserved body. Ordinary visible behavior and authorized private experience may be described without granting an extra information channel. Game UI/action declarations remain available even when the character cannot communicate. No factual world, cosmology, belief of a human player, release status or campaign authority is altered.

**ready**

KEEP accepted Ready: spend Action/cost/components/cadence at preparation, hold concentration, one pending Ready, open counter window then. End at next own regular START unless lawfully released/ended earlier. Trigger occurrence precedes Reaction release; revalidate actual target/range/line of effect/perception at release. No second payment, cast event or counter window on release. Effect clocks begin at release. Incapacitated can end the hold; Mental Collapse alone does not. A suppressed release loses its payload without a banked later effect.

**specialization**

KEEP actual Wizard Enchantment specialization: a creature failing its INITIAL save against an Enchantment spell may receive the printed extra control round when that class feature applies. Presence's native one-round failed-save control qualifies; record two future target ENDs for that actual specialist, retaining all normal endings. Power Word Stun has no initial save and receives no such extension. Mental Collapse's printed minute is at least one round: a genuinely qualifying Enchantment specialist may add one round, represented as six elapsed seconds to its absolute deadline, for66 seconds. This is the actual class modifier, not an increase to the native baseline. Prism and Rewrite are not Enchantment. The fixture Wizard specializes in Divination, so none of these five receives its +2 school DC or Enchantment extension. Exact other class hooks remain real; no invented elemental Prism classification grants Balanced Elements.

**native**

KEEP Frozen Time Prism: “Freeze 1 creature in place for 1 round, WIS save ends.” Conjuration; Druid/Mage/Wizard native rows; Action/120 feet/V,S,F/rank8/base21RP. The source contains no physical prism, shell, temporal suspension or named Frozen condition.

**targetAndAdmission**

NEW choose one perceived living finite creature, including self if otherwise legal, and resolve initial WIS against the actual class DC. Success establishes nothing. Failure establishes the defined immobilization unless its actual narrow defense prevents it. No whole-Action hard-denial admission is spent.

**payload**

NEW in place means Speed 0 in every possessed voluntary movement mode and no voluntary locomotion; it is support-relative, not a world-coordinate anchor. Ordinary Actions, Bonus Actions, Reactions, attacks, speech, senses, saves and concentration continue where otherwise legal. Forced displacement, an actually available teleport and transport by genuine moving support remain possible under their own sources. No collision shell, cover, damage immunity, object HP, weight, ice, Prone, Restrained, Root or elemental classification is added. Movement already spent stays spent; ending this restriction only recalculates remaining legal movement.

**timingAndEnding**

KEEP one hostile target round under the typed clock. NEW in initiative there is one ending WIS opportunity at the first FUTURE target regular START before expiry, excluding a START already processing at application. A success removes this application before voluntary activity; failure leaves it until the recorded END. An initial save is therefore not the only save, and the ending save can restore movement before the target acts. Outside initiative the single ending opportunity is application+3 elapsed seconds, if before expiry; retain that absolute opportunity through later initiative entry. On application in initiative, keep the original virtual START opportunity through later mode/order changes. Suppression at that opportunity loses it; no replay or substitute on resumption. Expiry still occurs. A same-owner refresh may retain a later lawful opportunity from the refreshing cast only if the prior opportunity was already consumed; never give two saves at one checkpoint. Exact spell termination/cure/target terminal end also ends it.

**physicalAndClockLimits**

KEEP all actual clocks and life/damage/concentration rules running. A genuine unsupported flying creature with no Hover/support exception enters Falling through the accepted Fall Marker; this spell supplies no immediate descent, invented flying profile or physical restraint. A real Hover/source exception works only in its exact scope. No source establishes a suspension of injury, poisoning, regeneration or source expiry. Unsupported flight/support/teleport examples remain branch holds, not fabricated positive campaign events.
