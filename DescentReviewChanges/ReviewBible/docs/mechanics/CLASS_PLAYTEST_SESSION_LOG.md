## What the test showed

- Which choices were useful, unused or impossible to activate?
- Did the Base character's identity work before Arch/Hero abilities arrived?
- Did later skills add decisions without erasing earlier skills?
- How often did turns lack an afford able action?
- Did a condition lock, healing loop, action loop or refill loop appear?
- Did one build over shadow another with similar investment?
- Which wording required a ruling? Quote the card ID and exact sentence.
- What single change should be tested next, and what result would support it?

Keep observations separate from proposed fixes. A single successful session is evidence, not universal balance approval.
