# Playtest Archive

This folder contains both **current table guides** and **historical simulation reports**.

## Current guides

- `NEWCOMER_PLAYER_GUIDE.md`
- `NEWCOMER_DIRECTOR_GUIDE.md`
- `RESONANCE_CHEATSHEET.md`

These are maintained against current canon.

## Historical reports

Simulation and expedition reports preserve what was actually tested at the time. Some therefore mention retired internal labels, alignment-affinity spell pricing, draft RP curves, or the former Burnout warning. Those reports are evidence of the development process, not current rules authority. Files that contain superseded magic language carry a **Historical rules snapshot** notice near the top.

For current magic use `../mechanics/RESONANCE_CANON.md` and `../mechanics/MAGIC_SYSTEM_VALIDATION_2026-07-31.md`.
