# Bestiary Publication Status

**Status:** Development scaffold, not final publication copy.

The current Bestiary pipeline exists to test encounter budgets, searchable creature data, ecology tagging, crafting drops, and companion-app ingestion across the full 100-floor campaign. It deliberately preserves broad coverage while the project replaces compatibility-origin placeholders with fully authored Aethel creatures.

## What is already original/current

- Gate Guardians and their Decennium roles.
- Aethel-specific ecology framing, zones, surface consequences, and Heartcell integration.
- The structured Excel → JSON → companion ingestion workflow.
- Current Aethel naming families such as Hush-Brokers, Order-Drones, Spiral Breach entities, Grief-Bound, Pact Devils, and Season-Bound Fey.
- Director-facing draft/provenance flags.

## What is still development material

A substantial number of ordinary creature concepts and stat shells remain compatibility/prototype placeholders used for balance coverage. They are intentionally marked as draft/sandbox where applicable and are **not cleared as final commercial bestiary copy**.

Before publication, the Bestiary needs a full creature-by-creature authorship, provenance, naming, ecology, and stat-expression pass. Where a compatibility placeholder remains useful mechanically, it should be replaced by an independently authored Aethel creature rather than merely renamed.

This distinction is intentional: the investor/development repository shows the working pipeline and game coverage, while the final commercial Bestiary will contain only material approved for publication.
