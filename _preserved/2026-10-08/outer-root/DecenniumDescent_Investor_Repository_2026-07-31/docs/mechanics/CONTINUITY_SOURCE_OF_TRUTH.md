## Priority

When current materials conflict, use this order:

1. **Explicit owner-approved canon decisions** reflected in `docs/canon/` or a current mechanics canon file.
2. **Player Rulebook** — player-facing mechanics, options, and public setting truth.
3. **The Director's Crucible** — Director-facing secrets, deeper cosmology, and adjudication.
4. **Structured companion data/code** — implementation mirror; should be corrected when it drifts from the books.
5. **Mechanics notes and playtests** — design/validation evidence; never silently promote an experiment to canon.

## Locked Baselines

- Opening: **2,400 hours / 100 days**
- Horn / point of no return: **1,200 hours / day 50**
- Dungeon: **100 floors / 10 tiers**
- Selectable base classes: **17**
- Fighter/Swashbuckler: legacy aliases only, not selectable base classes
- Umbrin: current product term replacing legacy Drow terminology
- Weave casters: **Resonance Points**, not a generic multiclass spell-slot pool
- Oracle: Revelation Charges, not Resonance Points
- Appendix B: mortal religion/cosmography, not omniscient proof of the universe's objective structure
- Player public origin: Calan'thir + Asmodeus established the known Crucible
- Director deep origin: Silent Ones/Old Ones created the older Heartcell structure; Calan'thir + Asmodeus later modified and governed it
- Unity: false resonance; never a synonym for ordinary peace, equality, trade, government, or cooperation
- Goblin susceptibility to Unity: Director truth, never universal guilt or racial morality

## Player / Director Boundary

Use `docs/canon/PLAYER_DIRECTOR_BOUNDARY.md` before moving cosmology into player-facing text. The public myth is intentionally usable and substantially true; later revelations add an older layer rather than declaring the entire setting primer fraudulent.

## Change Discipline

For a future material change:

1. identify which canon layer owns the fact;
2. edit the authoritative book or canon file first;
3. propagate the change into structured data and UI;
4. run textual consistency checks;
5. render and visually inspect any edited Word book;
6. retain only current decision records in the distributable repository.

Historical one-off audit and migration logs are not canon. They should not be cited once their decisions have been incorporated into the current books and canon briefs.
