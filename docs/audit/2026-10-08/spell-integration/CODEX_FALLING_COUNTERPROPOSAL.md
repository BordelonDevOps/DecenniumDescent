Resolve later Falling Steps at that marker once each round; extra turns never add steps. Everyone can have a normal Action opportunity before first impact; being unable/unwilling to act still matters. Outside initiative establish the order first and use a virtual start-of-round event as the initiating slot. Falling is a state of being unsupported, not hovering or permission for airborne walking.
