The 20 implementation decisions

One active buffer, one identity. Model temporary HP as one active BufferGrant with grantId, source/owner, remaining amount, expiry and any grant-linked riders. Incoming > existing replaces it; incoming < existing is discarded; NEW tie rule: equal amounts retain the existing grant by default, preventing an equal grant from refreshing duration. An exact source saying “replace” overrides that tie rule. Replaced/rejected grants never wait underneath.

Duration precedence. Explicit temporary-HP lifetime beats the V6 default, even if it could outlast a long rest. If no buffer lifetime is specified, expiry is the recipient's next completed long rest. One-round/start-turn/end-turn, 1-minute, encounter-end, while-form and explicitly source-linked zone/device lifetimes use their actual virtual/absolute markers. NEW integration: an ongoing source's general duration bounds its buffer only when the buffer is actually an ongoing component of that source; an instantaneous source with no buffer lifetime uses the V6 default rather than expiring instantly.

Payment precedes buffer arbitration. Once an activation legally resolves, RP/BG/Ki/use/Reaction/etc. are spent even if its buffer loses to a stronger existing grant. For Druid Buffer Reserve, offer=min(printed form amount, remainingReserve) and the entire offered amount is deducted before nonstack arbitration, not merely the improvement over the current shield. Losing grants do not refund Reserve or become latent future shields. Reserve capacity is recorded at the completed long rest: 2L+M; Form Surge Reserve records current PB there.

Grant-linked permissions versus independent riders. Bloodshield's once-while-they-remain Reaction attaches to the Bloodshield grant identity. If that grant is depleted, expires, or is replaced, the permission ends even if another buffer remains. Protective Verse's save advantage is a separate timed rider and survives replacement of its buffer. Soulbound's returned-creature state is separate from its 1-minute buffer. Arcane Sanctuary's attack rider is independently scheduled from each buffer grant. This source/effect/grant separation is mandatory.

Temporary HP remains mitigation only. It never raises normal HP, stabilizes, resurrects, ends Unconscious, removes Wounds, resets death counters or pays direct/sacrificial HP costs. HP-healing suppression does not suppress a separate temp-HP component unless the source explicitly says so. These boundaries are already supplied by Core/V6.
