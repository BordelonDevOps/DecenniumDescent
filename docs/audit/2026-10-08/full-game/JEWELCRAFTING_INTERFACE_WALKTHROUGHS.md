## Custody, meld, external priority and return

Use an ordinary fitted recipe-244 Crown: body value5 gp, mass0.5 lb, structural HP5/AC19, +1 Poison, maximum1 charge. It has no printed Load, so the existing body rule assigns provisional Load0.05 from its documented body mass. The actual wearer legitimately borrows it and records its head position before a lawful meld. The lender remains owner; the wearer has actual custody. It stays one physical item with one charge ledger.

Meld preflight counts its full0.5 lb and0.05 Load against the already established chain ceilings. While melded it is inaccessible and provides no modifier or charge activation. At a legitimate dawn it refills internally only if complete, positive-HP and unsuppressed. Actual suppression scope governs whether a particular suppression reaches it. This does not create access through the meld.

Suppose an independently acquired, genuinely compatible external Tailoring Hat occupies the head position when root anatomy returns. That external Hat has priority. The Crown cannot replace it or automatically designate a different position. In this scenario the root body's actual carried capacity and ordinary storage admit the Crown, so it returns carried and inactive with the same ledger. A later change requires the lawful equipping/removal Actions and actual fit. If no legal carrying or same-square/adjacent placement is available, the governing return procedure retains the single unresolved object in pending placement. Its actual elevation is preserved; mandatory reversion is not prevented, and ordinary falling is resolved under its existing procedure. No object vanishes, doubles or silently teleports to ground level.

A destroyed, transferred or irrecoverably lost Crown does not return from ownership metadata. A returning intact borrowed Crown in continuing actual custody does. Actual custody and current physical state, not a historical inventory copy, decide.

For an explicitly synthetic carrying arithmetic fixture, assume the transformed body's documented mass is10 lb and its governing casualty Load is1.5. With only this melded Crown, a rescuer must handle10.5 lb and1.55 Load. These supplied body values are scenario premises, not a new universal form profile. Recipe-268 is a +2 Fire mounted Gem, maximum3 charges, body0.05 lb with ordinary HP5/AC13. Its actual supporting garment remains a separate object. Merely suppressing that garment's magic does not detach the pin or destroy physical support. ## Creation at dawn and a damaged singleton

A source-valid recipe-242 Earring has one charge and is one piece. A mundane HP1/5 reserve can resolve singleton-Flawed at HP0/2 while its first lawful imprint still initializes the original maximum1 charge once. It cannot use that charge while Broken. Repair can make the same already-recorded charge usable; repair did not refill it.

If creation occurs at the same clock timestamp as dawn, the campaign's actual event order matters. Initialization records which dawn the authoritative campaign scheduler has already processed. A newly created item cannot spend and then replay an already processed dawn merely because both share a timestamp. The reference requires that checkpoint explicitly. Displayed time, transfer, rest and initiative never reset it.
