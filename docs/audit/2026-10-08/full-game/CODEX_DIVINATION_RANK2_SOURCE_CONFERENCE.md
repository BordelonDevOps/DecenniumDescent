# Eight rank-2 Divination identities — source conference

The twelve rank-one cards are promoted after the exact Fate Coin complete-roll timing repair. Only its resolution field changed. Fourteen promotion checks pass, including identical Mark Omen/Fate Coin guards in both cards and the shared overlay. Pipeline: 42 checks / 89,040 class-level access boundaries / zero issues. Catalog: 182 reviewed identities, 666 unfinished; 231 unfinished have any actual class rank 0–3. All 848 IDs and 936 placements remain. All currently unfinished Divination identities through rank one and Conjuration through rank three are authored; variants, higher ranks, wider systems, runtime, human balance and final GitHub delivery remain open.

Please reconcile these eight source packets into complete draftable instructions, ideally below 17,000 characters. I will return exact cards before promotion. Each is rank 2 / base 3 RP, Action / V,S,F. Actual access: Cleric and Wizard class 3; Mirrorsage and Shaman class 4; Ranger and Paladin class 5. All raw Core ranges are 30 feet, including effects explicitly promising one mile. Preserve the promises and conflicts. Mark added ranges, durations, target predicates, saves and other completions NEW. Avoid adding a biological “living” gate where the source says creature.

1. Augury — “Ask if action will lead to good/bad results (yes/no/unclear).” Instantaneous. This needs a useful decision forecast beyond Omen Whisper's cryptic clue. Define one specific proposed course of action, when it must begin, a finite forecast horizon, and whose concrete goal/interest establishes favorable versus unfavorable. “Good/bad” should not silently become moral alignment or the Director's preferred plot. Preserve the printed Yes/No/Unclear outputs rather than importing another game's full spell text. Clarify whether Yes means favorable and No unfavorable, or the caster poses a standardized binary question; mixed/neutral/unknown/protected results need a clear disposition. Distinguish current-circumstances likelihood from guaranteed future dice/choices; avoid an answer so hedged that every useful question is automatically Unclear. No forced destiny or retroactive event rewrite. A NEW 30-minute forecast window for a course beginning soon may be workable, but justify the exact window. Self informational casting versus raw 30-foot metadata also needs a decision. Materially equivalent inquiries with unchanged circumstances should not reroll a random answer or reveal extra hidden facts; genuinely different courses/goals remain usable. Normal paid casting, no unprinted daily cap unless specifically justified. Actual information protections can limit inputs without revealing which protection caused Unclear.

2. Divine Perception — “See if target is under divine influence (blessed, cursed, possessed).” Instantaneous. Need target creature/object/area and exact output: binary divine influence, specific listed categories, or more. Establish what makes an influence genuinely divine. The shared Core condition list does not itself provide universal Blessed/Cursed/Possessed condition records; Remove Curse specifically distinguishes an actual inflicted curse from a name containing curse and from an intrinsic Oracle Curse. Are the parenthetical categories examples requiring actual divine provenance, or does the spell expressly detect those states regardless of origin? Choose an explicit useful interpretation without class-name/theology stereotypes. A cleric casting a shared ordinary spell, a religious symbol, Evil alignment, a Corrupted condition or an Oracle class Curse is not automatically evidence of divine causation. Conversely, actual Director-held divine blessing/curse/possession facts should be revealable within the printed scope even if no software tag has yet been created. Undefined provenance versus established nondivine source must not become false certainty. No deity's true secret identity, full possession controller profile, exorcism/cure or mind control unless the source actually grants it. No save is printed.

3. Clairvoyance — “See OR hear a location within 1 mile.” Instantaneous metadata / raw30-foot range. Preserve the explicit one-mile effect. Need a specific known/identifiable location or a bounded way to select an unseen unknown point (source lacks Lesser Clairaudience's explicit “known” word, so any familiarity gate is NEW). Does the caster choose one sensory mode at casting, or may switch by Action? No simultaneous dual-mode feed unless explicitly added. Choose a finite duration/concentration policy for this otherwise undefined sensory effect; do not simply import another game's 10-minute concentration rule. Compare the reviewed lesser hearing spell: same-plane one-mile fixed point, one-minute no-concentration, local sound rules, caster retains local senses, Deafened/tether suppression, no originating LoE. A visual point needs viewpoint/orientation/field of view, ordinary lighting/obscurity, no automatic darkvision, no wall vision, no borrowing target senses. Define Blindness/Deafened by mode, whether local senses persist, no audio in vision mode and vice versa. Fixed versus free moving/panning, site in solid matter, physical versus nonphysical sensor, detect/dispel eligibility, one-caster point and ongoing same-plane/range gates must be explicit. Information protection applies subject by subject; no attacks/casting/LoE through a remote image.

4. Vision Trap — “Plant false sight into an enemy's mind; disorients and causes 2d6 psychic.” Instantaneous. The name does not by itself create a persistent placed trap. Need one enemy selected from ordinary information within30/LoE, an actual save type and damage success result. A finite mental visual distortion plus a soft combat penalty seems appropriate; source “disorients” is not an automatic grant of Dazed, Stunned, Incapacitated or whole-Action denial. The condition reference explicitly says only a source inflicting Dazed applies that condition. Could use INT save with 2d6 psychic and disadvantage on next attack on failure, or another precisely bounded source-faithful resolution. Define duration/consumption, repeated applications/stacking, and damage immunity versus the separate rider. Psychic/mental/illusion protections apply to actual scope; ordinary blindness or lack of a biological brain is not automatically immunity to a mental image unless actual source rules say so. No arbitrary behavioral commands, forced movement, lasting false memory, perfect counterfeit message, target mind-reading or identity revelation. Protection from Scrying blocks information gathering, not every noninformational Divination effect.

5. Locate Person — “Sense direction to a specific person within 1 mile.” Instantaneous metadata / raw30 range. Preserve remote direction without requiring the initial30-foot mark used by Soul Mark. Define sufficient knowledge of one unambiguous person: personal acquaintance, reliable identity description/name with actual unique referent, etc. No “nearest person matching guessed criteria” or magical identity search for ambiguous names. Does “person” need a campaign-established individual/personhood predicate, or any identified creature? Do not silently equate it to Humanoid or biological living. Define active undead/construct persons, dead/corpse eligibility and identity continuity after disguise/form change. Choose an instantaneous bearing versus a finite sustained sense; label any ongoing duration/concentration NEW rather than burying a metadata conflict. Same-plane one-mile gate, direction including vertical versus distance/route/condition, cover after selection, current target movement and exact anti-divination protections need rules. No direction should not identify whether the cause is range, plane, death, uncertainty or protection. Existing Soul Mark and Locate Object comparators are below; no new current-location sensor or free map from a bearing.

6. Faction Spy — “Observe activities at a faction headquarters for 1 minute.” Raw30 range, no concentration printed. This is genuine remote observation of HQ activities. The source does NOT print positive reputation, membership, Faction Seal invocation permission, special receiving infrastructure, or the known-public-entrance-only travel constraint from Faction Portal. Do not import those gates silently. Need one exact known canonical faction and a particular HQ if several exist. Must its precise physical location already be known, or can a clearly identified HQ (such as its established central headquarters) be the remote institutional anchor without its street address? Label a new knowledge condition explicitly. Define geographic/plane reach: source has no one-mile cap, unlike Clairvoyance, so don't silently limit a distant-HQ promise merely for compatibility. Any-distance same-plane may be a bounded useful interpretation; actual interplanar observation needs an explicit decision.
What activities are visible: one fixed identified room/viewpoint, a Director-selected main activity space, or multiple rooms? Avoid arbitrary useless foyer-only results and omniscient access to every secret vault/document. Define sight versus hearing, ordinary local light/walls, field of view/orientation, caster Blindness/Deafened, local senses, viewpoint creation in solid matter, movement/panning, and one-caster feed. No remote attacks/spells/LoE or public recording. Actual protected persons/rooms can block their own information, not automatically erase the entire HQ's unprotected activity. HQ destroyed/relocated/no longer belongs to faction, caster plane changes, or suppression during duration should have defined behavior. The source's one-minute clock stays; no reputation gain, credentials or permission to enter.

7. Alignment Prediction — “Foresee how a creature will act based on their alignment.” Instantaneous. Must provide a useful behavioral forecast, not merely repeat Alignment Sense or dictate a PC's conduct. Existing Core/condition integration expressly states alignment does not compel conduct, PvP, party separation or automatic oathbreaking. Need one specified imminent interaction/situation and a finite forecast horizon; use actual individual facts including alignment, not “all Lawful creatures obey”/species/religion/faction stereotypes. Define output as one most likely voluntary response on current circumstances, with genuine conflicting possibilities/undefined alignment/protected information reported appropriately. Do not make every exercise of free will an automatic failure to answer. Future choices and genuinely changed circumstances can change the forecast; no forced decision, truth guarantee or future die transcript. Should actual axes be separately disclosed? Source promises behavior, not necessarily a free exact alignment reading or complete motive scan. No unprinted saving throw unless proposed as NEW. Repeat materially equivalent scenario under unchanged circumstances should not sample every possible future; genuinely different scenario can be queried normally.

8. Resonance Tracking — “Follow the trail of a spell cast within the last hour.” Instantaneous metadata. This needs an actual trail procedure, not just a report that magic happened. Biggest ambiguity: what trail? The spell effect's actual spatial path/endpoints, a route back to its casting origin, or a continuing trail of the caster after that casting? Choose and explain rather than leaving “trail” undefined or quietly replacing it with Locate Person. Need select one qualifying casting event/trace at or within30feet, whether the event must be observed/known or the most recent unknown trace may be selected. Multiple traces need deterministic choice without creating unrestricted identity/secret-rank enumeration. Define initial one-hour age test and whether residual evidence independently ages out at original cast+3600seconds while the tracking spell runs; a recast/copy must not refresh an old cast's age.
Choose finite duration/concentration and actual following procedure: visible/private local trail segments, direction at forks, cross-wall/occluded geometry, ability to follow toward caster-origin versus effect endpoint, ordinary navigation/time/movement, teleport/portal/planar discontinuities. No physical trail should be fabricated along a path the original magic never traversed. If instead the chosen interpretation follows the caster's subsequent route, explicitly say that is NEW and provide its real range/plane/identity/age limits. Tracking should remain useful for an actual spellcasting clue, including self/instantaneous effects, without claiming every spell physically draws a line through the world. Define whether committed-but-countered casts, magical items, class techniques and copied effects qualify: only actual spell casts should get the one-hour predicate unless another source explicitly qualifies them. A copy is not automatically a fresh cast. Specific protections can block protected subject information; no spell name/rank/currentcasterlocation/hiddenidentity merely from following the trace unless exact source evidence warrants those outputs. No residue harvesting, free RP, moving old cast timestamps, or recursion creating new evidence.

Shared rules: one-minute duration = tenth future caster regular-start, outside+60seconds; hour=3600elapsedseconds. Preserve virtual/absolute endpoints through initiative/death/plane changes. Costs/concentration/beginning hooks before Counterspell; no refunds. Exact school/target protections retain their scope. Saves binary; attacks/tasks keep their actual Core systems. Per-caster replacement only on successful new application; no stale cleanup of replacements. These are authored tabletop procedures, not a request to finish the global simulator before writing.
