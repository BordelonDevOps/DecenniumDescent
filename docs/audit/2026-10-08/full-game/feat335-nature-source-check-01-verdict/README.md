## Reproduce the executed evidence

Python standard library only. From an extracted copy of this evidence folder:

```text
python -X utf8 reproduce_nature_source_checks.py /path/to/DD_FEAT335_Nature_Source_Check_01.zip > reproduced.json
```

Decoded JSON should equal `EXECUTED_SOURCE_CHECKS.json`; UTF-8 LF output matches byte-for-byte. Optional `--descendants /path/to/new-scratch-directory` emits the same three complete files without editing the input ZIP. It refuses to overwrite a differing existing output. No game application, imported borrowed helper or network is required.

These checks verify the submission, source bindings, exact amendment/inverse/preservation, full text/object parity and small reference calculations. They do not execute Nature's full gameplay procedure or authenticate campaign facts. The submitted362-check report is not relabeled as a new reviewer run. The16 focused groups in `FINITE_NATURE_EXPECTATIONS.json` are authored acceptance expectations for local follow-through, not executed results.

`NATURE_CONTROLLING_RECORD.json` identifies the new authority and descendant hashes. Use a separate local fulfillment record; do not overwrite original sourceVerdictSha256, original sourceBindings, former artifact hashes, receipt records or current selection/status fields.

`FILE_MANIFEST.json` binds every evidence payload except itself. The original submission's manifest is separately bound in `SUBMISSION_BINDING.json`; it remains the source submission manifest, not a manifest of these descendants.
