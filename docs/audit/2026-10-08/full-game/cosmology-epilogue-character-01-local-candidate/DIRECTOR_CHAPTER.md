### Puzzle solution

**question:** Which lamp opens the sealed archive door?

**knowledgeLimit:** The Sentinel observed this local lamp mechanism and riddle only; it does not know the archive contents.

**puzzle:** Exactly one plaque is true. Lamp First plaque: 'Second opens the door.' Lamp Second: 'This lamp does not open the door.' Lamp Third: 'First does not open the door.' Exactly one lamp opens the door. Which?

**answer:** First. If First opens: plaques evaluate false/true/false = exactly one true. If Second opens: true/false/true = two true. If Third opens: false/true/true = two true. Therefore First is unique.

**reward:** Sentinel states 'First' and the truth-table reasoning once. Operating the real lamp remains required.

**ordinaryInvestigation:** 20 minutes examining wiring; INT (Investigation) DC15 reveals which lamp circuit reaches the door latch. Failure gives uncertainty, not a false answer.

**operation:** Lighting a lamp is one Action. Correct First opens the door. Wrong lamp causes harmless circuit lock for 1 minute, then resets; maximum three wrong attempts before mechanism stays locked until ordinary repair.
