All29 table rows match the preserved equipment source catalog field for field. Missing values remain missing, including literal comma placeholders; none becomes zero or a guessed weight.

The Known Descent book contains no exact candidate-mount-name paragraph match, including paragraphs in tables. That bounded search does not prove no source exists elsewhere. Cavalry and Mounted Combatant are retained in full with their pending feat status. All17 class collections/1223 cards are available for comparison; the recorded literal search has zero mount/vehicle matches, but movement, leap, custody and timing hooks still need explicit adjudication. No class or feat approval follows.
