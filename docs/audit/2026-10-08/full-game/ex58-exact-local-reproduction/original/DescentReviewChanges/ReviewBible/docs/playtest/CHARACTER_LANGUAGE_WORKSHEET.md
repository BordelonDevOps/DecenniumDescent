# Character language and communication record

**Reviewed authored teaching/presentation — TEX-EXACT-2026-10-11.** This is a paper-friendly way to keep the eight records in the [reviewed language contract](../../data/playtest/language_communication_candidate_public.json). The worksheet's authored presentation is jointly reviewed; human use remains untested. It adds no language, skill, spell, class feature, discount or device permission.

Use the [language chapter](../mechanics/LANGUAGE_COMMUNICATION_PLAYTEST.md) for procedures and the [32 worked sequences](../mechanics/LANGUAGE_COMMUNICATION_WORKED_SEQUENCES.md) for timing examples. Start with forms 1 and 2. Copy the other forms only when that activity actually occurs. A blank is unfinished information, never permission. Keep the source record with the character sheet; there is no need to recalculate a source fingerprint during play.

## 1. Languages and modes

Copy one entry for each actual language competency. Keep an original spelling beside the resolved language identity. A dialect or register is recorded only when the source actually supplies it. Similar names and shared characters do not grant comprehension of another language.

Keep current physical restrictions on form 3 or the normal condition sheet. Being unable to hear, speak, see or write now does not erase the knowledge above. A written-only competency does not acquire speech. Combine duplicate fixed grants only by their genuinely granted modes and keep all sources; they give no replacement language.

**Mira's existing example:** the [first Bard walkthrough](FIRST_BARD_WALKTHROUGH.md) records Common and chosen Dwarvish from Human. Each has the ordinary spoken comprehension, speaking, reading and writing modes under LA-04. Her Nomadic Human variant adds no language. Battlefield Medic has no source Languages field and adds none. Keep Dwarvish's choice entry and the Human source; do not manufacture a background language or infer other languages from its script.

## 7. Communication when order matters

Use this event form for a disputed message, interpretation, cue or feature delivery. Ordinary conversation does not require filling it for every sentence. Keep only the detail needed to establish the actual channel, recipients, timing and budget.

| Event record | Fill from what actually happened |
|---|---|
| Event reference; actual sender; intended recipients | ____________________ |
| Channel: spoken, written, rehearsed cue or actual feature; source feature if used | ____________________ |
| Specific available content and language/mode evidence for sender and recipients | ____________________ |
| Actual hands, senses, voice, path, costs and consent | ____________________ |
| Ordered delivery start and finish events | ____________________ |
| Interpretation chain: incoming receipt, interpretation, outgoing delivery | ____________________ |
| Actual recipient receipts, arrival events and supported comprehension | ____________________ |
| Numbered round and aggregate ordinary seconds used | ____________________ |
| Actual Actions or readied permission where required | ____________________ |

Ordinary free communication is an aggregate six seconds per creature per numbered round. An extra turn does not refresh it; each extra six-second segment takes the actual Action required by the chapter. Interpretation takes its actual ordered time. No receipt or Reaction window occurs before its delivery. A hearing-only effect still requires actual hearing. Player explanations and accessibility arrangements are not fictional character speech unless the character actually communicates.

## 8. Source record kept with the sheet

Copy one entry for every actual grant or derived rule used above. When using digital records, preserve the exact source path, SHA256 fingerprint and record ID; on paper, keep the corresponding source reference with these details in the campaign's source register. A label or fingerprint alone does not prove that a character acquired a feature.

| Source record | Preserve the actual evidence |
|---|---|
| Original source path and exact record ID | ____________________ |
| Source SHA256 fingerprint / matching source-register reference | ____________________ |
| Actual authority for this grant or derived effect | ____________________ |
| Presence of the original field | Absent / null / value |
| Original value, only as permitted by the presence state below | ____________________ |

For **absent**, retain that the original field did not exist and omit the digital `sourceSpelling` key entirely. For **null**, retain literal JSON null. For **value**, preserve the exact original non-null JSON value, including an empty string, array or object. Do not substitute a canonical spelling or normalize an empty value. These are three different records: Battlefield Medic's absent Languages field is not a null field or an empty grant. Canonical identity belongs on form 1, beside the preserved source spelling.

All forms follow the [LAX review status](../mechanics/LANGUAGE_REVIEW_STATUS.json). Broader character integration, pending effects, human usability and the companion implementation remain separate work. This worksheet does not migrate an existing save.
