### MC3-MEMORY-120

NEW two-spell episodic-history completion; inherits accepted Disrupt Memory distinctions

All memory intervals use exact elapsed timestamps and half-open [start,end) boundaries. Prior experiences at the lower bound qualify; experiences at resolution time itself do not. Actual memory/mind defenses apply only within their own text. No private event IDs, unseen roster, DC, source identity or eligibility reason are exposed to a caster by success/failure.
