### 6. Copied-feat Ready — one payment, bounded use in both touched rounds

`COPY-READY-ALLOWANCE-01` resolves the specifically queued cross-round question for the seven FS08/SUP07 profiles used by Arcane Adaptation, Eldritch Echo and Mimicry.

**The selected consequential choice:** preparation spends its round's feat-copy allowance, plus an actually owned applicable Mirrorsage shared allowance, before the counter window. Same-round release reuses this hold's own tokens. A later-round release must also have and atomically spend that later round's applicable allowances. It does not move or refund the earlier spends. Thus cross-round Ready uses an allowance in both rounds but pays RP/components/capture permission/strain/history only once.

This prevents countered preparation spam and a delayed copy plus another same-round copy bypassing the cap. It is an explicitly selected authoring choice, not an assertion that the old source already specified it. Failed validation/declined or cap-blocked release cannot partially debit another ledger or spend the Reaction. Valid competing uses need their own genuine action permission; the hold supplies none. The complete identical wording is synchronized through FS08, SUP07, all six affected feat operative strings and three acquisition-contract mirrors. FS09 chronology/strain, actual acquisition requirements, original source objects and false selection/runtime flags remain unchanged.
