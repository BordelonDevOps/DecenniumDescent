## 1. Eyes of the Divine — approved

The card correctly requires **actual sight of the current appearance** before targeting. It does not inherit True Sight (Lesser)'s unseen-creature detection.

Approved distinctions:

- mundane disguise → readable undisguised current appearance;
- magical visual disguise/illusion → readable appearance beneath it;
- actual transformation → transformation status only if that fact itself is readable;
- underlying/base form → only an actual current source-recorded underlying/base-form record;
- protected transformation existence and protected underlying appearance are independent information fields.

It therefore does **not** invent a former biological body beneath a permanently changed baseline, reveal legal identity/history, or automatically pierce information protection.

No repair.

## 2. Future Echo — approved

The bounded tabletop scheduler is coherent and does not require enabling the wider Time Loop runtime.

I specifically approve the **cast-only-while-initiative-exists** interpretation:

> Outside initiative, the cast is legal but has no scheduling effect and refunds no committed cost.

There is no meaningful “next numbered round” outside an encounter, and carrying an indefinite schedule into some future encounter would be a much larger unsourced power.

The boundary procedure is also approved:

1. current round completes;
2. normal end-round events complete;
3. prior Future Echo permutation restores to baseline while retaining legitimate changes from other initiative rules;
4. pending Echo schedules resolve in stable order;
5. each application claims its remaining selected participants;
6. those creatures permute only among their own remaining baseline slots.

A singleton being claimed despite not physically moving is correct because it prevents a later Echo from hijacking that participant.

Also approved:

- no concentration;
- eligibility/willingness/range checked at cast resolution;
- no later range tether;
- caster death alone does not erase an independent pending schedule;
- loss of an actual regular slot filters that creature;
- suppression/unavailability exactly at execution means expiration without makeup;
- executed permutation becomes a fixed one-round scheduling decision rather than an ongoing dispellable state that could be removed midround;
- a fresh Echo during the affected round may schedule the following round after restoration;
- existing virtual duration, periodic, fall, recovery and absolute clocks do not migrate with initiative;
- one actual regular turn still creates exactly one normal start/end sequence.

This is correctly documented as a **NEW tabletop scheduling interface**, not a claim that the runtime adapter already exists.

No repair.

## 3. Reveal Weakness — approved

The save-event distinction is correct.

An event explicitly classified as a saving throw consumes Reveal Weakness, including an actual concentration or death save if its rules classify it that way.

If that saving-throw event has an **automatic result with no die**, the pending effect is consumed but cannot change the automatic result because disadvantage has no roll to modify.

If an immunity means **no saving throw event occurs at all**, there is nothing to consume it.

Also approved:

- no initial save;
- one-minute caster-source clock;
- next save of any actual type rather than caster-spell-only;
- pre-resolution consumption;
- normal advantage/disadvantage cancellation;
- no automatic failure or retroactive result alteration;
- cross-caster one-pending-record replacement.

No repair.

## 4. Planar Window — approved

The public/private interface is sound.

### Public window
Ordinary remote **vision** displayed through the fixed local window. Lighting, smoke, walls, terrain and observer Blindness apply.

### Private native detection
Separate magical information delivered to the caster. It does **not** require the caster continuously to look at the local window.

I approve having **no continuing 60-ft caster tether** after valid local placement. The printed 60 ft governs placement, while concentration controls continuation. Caster movement therefore:

- does not move either fixed point;
- does not pause concentration;
- does not end the window merely for exceeding 60 ft.

The native detection correctly avoids becoming a universal invisible-creature scanner:

- an actual readable native being/effect can be located despite Hidden/Invisible/non-solid concealment;
- an otherwise visible presence with unreadable native provenance can report `Indeterminate`;
- an unseen creature of undefined provenance is **not** revealed merely because its origin might be unknown.

Destination validity and wards resolving **after payment** is also correct, with failed/blocked feeds nondiagnostic.

No repair.

## 5. Speak with Dead — approved

The dual placement remains correctly preserved:

- Divination when cast through the listed Divination access rows;
- Necromancy when cast through Crimson Agent, Druid or Thief;
- no school/class-list union.

The interview structure is approved:

- substantial apparent remains may be selected before hidden eligibility is known;
- eligibility resolves after payment;
- casting Action itself asks **zero** questions;
- each question/answer exchange afterward uses one Action in initiative or about six seconds outside initiative;
- each independent inquiry consumes its own allowance;
- up to five per application;
- one-minute duration;
- audible question within 60 ft/LoE;
- audible answer from the remains;
- no physical tongue requirement;
- spent exchange remains spent when answer is unknown, untranslated, or protected;
- fresh paid applications may establish separate five-question ledgers;
- no invented daily immunity/exclusivity.

### Fragment/memory boundary

I explicitly approve the authored rule:

> **Memory available through a particular remnant is the actual retained memory associated with that remains/death context; an old surviving fragment does not automatically acquire memories from a later resurrected life.**

Example: a person dies, leaves a severed bone fragment, is resurrected, lives five more years, then dies again. The **old first-death fragment** does not magically acquire the five later years merely because the same identity is dead again. Appropriate remains associated with the later death may carry the later retained memory record.

That completion prevents detached remnants from functioning as permanently synchronized identity backups while preserving that multiple fragments from one death are not separate people/souls.

Also approved:

- while the identity is currently living, old remains are ineligible;
- return to life ends an active interview;
- destruction/loss of the selected qualifying remains ends its anchor;
- Soul Bind's resurrection prohibition alone does not erase memory;
- subjective remembered belief can be mistaken, but the echo itself does not deliberately lie.

No repair.
