# Quickstart roll alignment

The level-one quickstart previously presented the four-degree task procedure under a generic roll heading, without separating attacks or saving throws. That could make a reader apply task critical shifts to the wrong roll type.

The quickstart now distinguishes attacks, ordinary saves, and task/skill/tool checks using the already reviewed `CORE_RESOLUTION_PLAYTEST.md` Rolls section. Its original task degrees remain. This introduces no new resolution rule; it brings the onboarding summary into agreement with the current candidate.

The complete previous quickstart is preserved in `QUICKSTART_LEVEL_1_BEFORE_ROLL_ALIGNMENT.md`. All expedition, settlement and other quickstart text remains unchanged. This correction does not complete character creation, onboarding, or final game flow.
