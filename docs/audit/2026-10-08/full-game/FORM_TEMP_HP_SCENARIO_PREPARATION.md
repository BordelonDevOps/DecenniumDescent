# Form and buffer scenario preparation

Prepared while the175+5 source conference is being discussed. These are adversarial situations for checking the eventual decisions, not adopted new rules or evidence of completion.

| Situation | Decision or invariant to exercise |
|---|---|
| Existing shield12 has1 second left; incoming shield8 lasts1 minute. | Larger-remaining arbitration must not silently give12 the new minute or keep8 underneath. |
| Equal shield values from different sources have different expiries and linked riders. | Explicit tie policy selects one complete grant identity; no combined best-of-both shield. |
| One attack consumes part of a buffer and a second grant arrives. | Compare remaining amount, not original grant maximum. No ordinary healing repairs a buffer. |
| A paid buffer offer loses to a larger existing shield. | Resolve whether/how finite payment commits; no unpaid retrigger or reserve refund by rejection. |
| Overflowing Light's remaining shield is replaced just before natural expiry. | Replacement is not natural expiry; no duplicate condition-cleansing event from a discarded grant. |
| Overflowing Light naturally expires with1 point remaining; identical deadline also ends a form or zone. | Stable expiry ordering, one source-qualified cleanse, no later replay. |
| Bloodshield is replaced by another source while its duration continues. | Its once-while-these-points-remain Reaction cannot borrow the replacement shield's identity. |
| Protective Verse buffer is depleted before its saving-throw rider is used. | Separate buffer identity from any independently timed rider. |
| Field Medic stabilizes a creature at0 and supplies a buffer. | It remains at0/unconscious; later fully absorbed damage follows the reviewed Stable/death-failure boundary. |
| A living creature at0 is under HP-healing prohibition but legally eligible for a buffer. | No automatic resurrection/healing interpretation, and no automatic ban on the separate buffer component. |
| Direct HP sacrifice has enough tempHP but insufficient real HP. | TempHP cannot pay the sacrifice or evade its minimum-real-HP gate. |
| Mooncursed Howl has3 allies but only9 Buffer Reserve after rolling12. | Specify recipient selection/order/allocation and reserve payment atomically; no3×12 from9 points. |
| Enter Bear while another source's shield exceeds the Bear reserve offer. | Payment, grant comparison and form dependency stay separate; subsequent reversion must not remove an unrelated retained shield. |
| Level20 Druid changes Bear→Wolf→Bear repeatedly. | No restored real HP, Buffer Reserve, Surge Reserve, long-rest powers or Dissonance; exact Refrain behavior still applies to legal transitions. |
| Druid renews the identical form versus truly changing form. | Explicit distinction for new instance identity, once-transformation uses, duration and protected Refrain reset. |
| One incoming damage event depletes form buffer, reduces own HP to0 and invokes a would-die replacement. | Process one character HP/Wound event with exact form-ending order; no separate beast HP overflow, heal or second damage event. |
| A flying form ends over a pit from incapacity. | End flight and adjudicate the real fall through existing movement/hazard rules; no safe landing or free reversion teleport. |
| Carrion form ends while a separate paid Base Swarm persists. | End only actual form-dependent bodies; preserve independent source concentration and clocks. |
| Equipment is melded into a form and has armor, a numeric magic bonus and a consumable component. | No duplicated armor; preserve only compatible numeric bonuses; no use of melded objects/materials by assumption. |
| A Bard starts a Chant, maintains it, ends early, creates a residual note, then uses an Echo. | Only the source-authorized start/pulse events generate each distinct buffer; maintenance/residual/Echo cannot imitate Chorus Shield. |
| A Paladin redirect-to0 gives the ally a buffer after the redirected event. | Preserve actual absorbed amount and source cap; no retroactive absorption of the trigger or extra resource chain. |
| A paid Smite meets both King's Smite and Noble Bearing. | One replacement grant, with no duplicate shields or copied Smite. |
| Channel Life has excess healing and the recipient owns another excess-to-buffer converter. | Packet-wide prohibition still blocks that conversion; one point cannot be owned by two converters. |
| Chef prepares food during the same long rest that expires old default buffers. | Resolve explicit completion/eating timing; no grant immediately lost through accidental event order, nor indefinite stockpiled meal buffs. |
| Soul Cage sees one death represented by multiple body pieces or a repeatedly revived friendly summon. | Single real event identity and exact charge eligibility; no duplicated soul charges or generated black crystals. |
| Necrotic Affinity resistance, its Reaction and an existing buffer all apply. | Define amount captured at the agreed damage stage, prevention versus post-damage grant, and no double resistance or recursive absorption. |
| Oracle Spirit Walk exposes both body and spirit to one area event. | One character identity, HP state and expenditure; no cloned target damage/healing/resource pools. |
| Existing Shapechange/Polymorph spells reference generic creatures without operational profiles. | Keep exact unresolved profile/agency/duration dependencies visible; spell name alone cannot import a monster stat block. |

Tests should target these consequences after the rules are reconciled. The guide and source-specific operational bindings must also give a tabletop reader the actual procedure; a passing helper is not a substitute for readable rules.
