| Warrior | Medium; Heavy | Martial weapons | None |
| Wizard | None | Daggers; darts; slings; quarterstaffs; light crossbows | Arcana tools; scribe's supplies |

A named weapon, kit, relic, focus, kama, nunchaku or other implement still requires an actual equipment record for its statistics and use. Proficiency does not grant ownership or create an item profile.

Bard instruments use the ordinary improvised-weapon procedure without an invented die or extra attack. The Cleric favored weapon is one already-existing mundane record chosen and recorded at creation, with no free later change. Ranger’s dagger/shortsword/scimitar definition is a new bounded interpretation of “dual-wielded blades”; it does not remove normal wielding requirements or grant a second attack.

Soldier sidearms must be explicitly classified in actual equipment records; the equipment pass still has to supply those bindings. Warrior mutation-tagged gear is a bonus-eligibility hook, not a proficiency category. Mage/Wizard Wand, Staff, Arcane Staff, Spell Focus and Spellblade source labels grant no weapon statistics or magical powers by themselves. Druid retains its nonmetal restriction. Monk’s Unarmored Flow follows its own card.

A legitimate tool check adds proficiency once if trained; skill plus tool training does not add PB twice. Arcana tools, religious implements, divination tools and survival tools remain source-preserved proficiency labels, with actual equipment procedures still required.

## Multiclass entry

On taking a new Base class, meet the listed scores for every existing class and the new one. These are not requirements for creating a first-level single-class character. Use only the new class’s proficiency row below; no extra starting saves, full starting skill list, equipment, wealth or background.

| New class | Minimum scores | Proficiencies gained once on entry |
|---|---|---|
| Bard | CHA 13 | Light armor; one skill of your choice; one musical instrument |
| Cleric | WIS 13 | Light armor; medium armor; shields |
| Crimson Agent | DEX 13, CON 13 | Light armor; one skill from this class's list |
| Dragoon | STR 13, DEX 13 | Medium armor; shields; martial weapons |
| Druid | WIS 13 | Light armor; medium armor; shields — no metal armor or shields |
| Mage | INT 13 | One skill from this class's list |
| Mirrorsage | INT 13, CHA 13 | One skill from this class's list |
| Monk | DEX 13, WIS 13 | Simple weapons; shortswords |
| Oracle | WIS 13, CHA 13 | Light armor; one skill from this class's list |
| Paladin | STR 13, CHA 13 | Light armor; medium armor; shields; simple weapons; martial weapons |
| Ranger | DEX 13, WIS 13 | Light armor; medium armor; shields; simple weapons; martial weapons; one skill from this class's list |
| Shaman | WIS 13, CON 13 | Light armor; shields; one skill from this class's list |
| Soldier | STR 13, CON 13 | Light armor; medium armor; heavy armor; shields; simple weapons; martial weapons |
| Thief | DEX 13 | Light armor; one skill from this class's list; thieves' tools |
| Tinker | INT 13, DEX 13 | Light armor; one skill from this class's list; tinker's tools |
| Warrior | STR 13, CON 13 | Light armor; medium armor; shields; simple weapons; martial weapons |
| Wizard | INT 13 | One skill from this class's list |

These deliberately preserve the book’s separate multiclass rows even where they are broader than a detailed first-class chassis: for example, Dragoon entry grants shields and martial weapons, and Soldier entry grants simple/martial weapons. They are not merged back into first-class starting lists. Paladin’s starting Martial Proficiency card cannot bypass the multiclass table to grant heavy armor.
