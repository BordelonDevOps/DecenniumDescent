## Q3 — Authorship (canonical division)

> **Public:** Calan'thir and Asmodeus built the dungeon (Crucible / Calan'thir's Trial). Neutral ground, proving ground, controlled release for ambition, monument of Order+Hell cooperation. Cultures argue credit; virtually everyone accepts joint creation.
>
> **Secret:** Silent Ones/Old Ones built the actual machinery (Heartcell, 100-floor resonance, ten Gate divisions, opening cycle, reward architecture). Calan'thir & Asmodeus discovered/claimed/modified/activated/bound themselves to it — they did not invent the underlying machine. Treasure is bait. Expeditions serve the machine (combat resonance, death essence, gate victories, loot spreading, conditioning).
>
> **Formulation:** "The Silent Ones built the prison. Calan'thir and Asmodeus taught the world to call it a dungeon."
>
> **Player knowledge:** Public myth is the only *complete* explanation at the start — not "players never hear truth." Truth emerges via contradictions across floors (early architecture predates scripts → Custodians/Bearers/Signatories → Pact governs but didn't originate → Heartcell operating cycle). Discoverable, never commonly known. World shouldn't know; a successful party might.

**Effect:** Resolves round 1's open question #2 ("public builder vs secret builder — cover, partial truth, or separate cosmic event?"). **Answer: neither cover story nor separate event — a two-layer truth.** Calan'thir and Asmodeus are **real, joint, public builders of the Crucible / Calan'thir's Trial** (not liars, not a myth planted by the Silent Ones) — but they **discovered and repurposed** a pre-existing machine (**the Heartcell**) that the Silent Ones/Old Ones built first. Calan'thir and Asmodeus's role is discoverer/claimant/modifier/activator/binder of the machine, not its inventor. Also resolves round 1's open question #3 ("loot-as-bait vs. dungeon-contradicts-Old-Ones — one mechanism or two?"): **one mechanism.** The resonance-generation the Matrix of Oblivion extract describes (combat, death, gate victories, loot circulation, conditioning) **is** the machine's operation; loot-as-bait is the on-ramp that feeds it.

**New term locked:** **Heartcell** — the core machinery the Silent Ones built beneath the public Crucible (100-floor resonance structure, ten Gate divisions, opening cycle, reward architecture).

**Player-knowledge model locked:** the public myth (Calan'thir + Asmodeus, Crucible, joint Order+Hell monument) is not a partial lie fed to players — it is genuinely the *complete* explanation available at the campaign's start. The deeper truth is **discoverable** through in-fiction contradictions (an ordered list of clue-tiers: architecture predating any written script → Custodians/Bearers/Signatories → the Pact governing but not originating the machine → the Heartcell's operating cycle) but is **never common knowledge**. The wider world never learns it; a sufficiently successful party might.

**Supersedes:** [`SILENT_ONES_CANON.md`](./SILENT_ONES_CANON.md) §2 term-mapping row "Calan'thir & Asmodeus / Crucible" (was "reconcile as competing myth vs secret truth until owner resolves" — now resolved as **two true layers, not competing**); [`DUNGEON_CREATION_PURPOSE.md`](../playtest/DUNGEON_CREATION_PURPOSE.md) Owner-lock reconciliation table row "Who built it" and open questions 1–2.

## Q4 — Clocks

> Opening: **2400 hours / 100 days**. Horn sounds at **1200 hours / 50 days** = **point of no return**. Update DESCENT_WINDOW_CANON — this supersedes treating 120h as the only horn (previous companion 120h may be wrong or a different micro-budget — **flag** prior 120h as superseded by this owner lock unless owner clarifies later; stamp clearly that horn = 1200h / day 50 PoNR inside 100-day opening).

**Effect:** The **2400-hour / 100-day opening window is unchanged and reconfirmed.** What changes: the **horn** — the event previously modeled purely as an unrelated **120-hour underground micro-clock** — is now locked as **1200 hours / day 50, the halfway point of the same 2400-hour opening, and the point of no return (PoNR)**.

**Explicit owner caveat preserved verbatim (do not resolve on the owner's behalf):** the prior 120-hour figure "**may be wrong or a different micro-budget**." Two readings remain open:

1. The 120-hour figure was simply a mistaken stand-in for the real horn (1200h/day 50) and should be retired.
2. The 120-hour figure could still describe a genuinely different, smaller clock (e.g., a per-delve underground budget nested somewhere inside the 100-day opening) that the owner has not yet reconciled against the 1200h/day-50 PoNR.

**Default treatment per owner instruction:** flag prior 120h as **superseded** unless/until the owner clarifies otherwise. This is a flag, not a deletion — code and several docs still implement/describe 120h (see code/doc debt below).

**Supersedes:** [`DESCENT_WINDOW_CANON.md`](./DESCENT_WINDOW_CANON.md) §2 "Relationship to the 120-hour horn" (previous framing: two unrelated clocks, macro vs micro, "do not merge or substitute one for the other" — now superseded by the 1200h/day-50 PoNR reading).
