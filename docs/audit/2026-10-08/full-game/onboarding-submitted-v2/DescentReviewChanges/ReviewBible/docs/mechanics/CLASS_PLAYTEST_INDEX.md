# Class playtest library

Start with a Base-level character. Enter its Arch progression only at the stated gate and choose one Hero path later. Druid, Oracle and Paladin have explicit progression exceptions; forms, Mysteries, Curses and Oaths are not additional Base classes.

The packets provide costs, actions, targets, durations, frequency, source wording, progression and worked turns. They preserve the protected class engines and call out new rules where the sources were incomplete or conflicting.
