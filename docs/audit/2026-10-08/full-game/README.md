## Script distinction

Audit-local `record_*`, `update_*`, `promote_*` and conference-authoring scripts document historical transformations. Do not rerun them as a general build: some intentionally write the state from their particular review stage. Their presence is audit evidence.

The current `ReviewBible/tools/build_*` and `validate_*` references provide scoped rendering and verification. Read each script's scope before running it. Source integrity, a passing reference test and an individual GPT review are separate evidence stages. Neither a source count nor a lexical search closes a game domain.

Approved books, captured class/spell sources, rejected alternatives and raw notebook responses remain preserved. No whole-game completion or human balance claim follows from a bounded interface closure.
