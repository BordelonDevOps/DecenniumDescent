# Eight rank-3 Divination identities — source conference

The eight rank-two Divination cards have completed exact review, promotion and validation. Current catalog: 190 reviewed identities / 658 unfinished, with all 848 IDs and 936 placements retained. 223 unfinished identities have some actual class rank 0–3. No currently unfinished Divination identity at rank 0–2 or Conjuration at rank 0–3 remains. Identity coverage does not close unassigned variants. Wider systems, runtime, numerical balance and final whole-game/GitHub review remain open.

Please reconcile these eight source packets into complete draftable instructions, ideally below 17,000 characters. I will return exact cards before promotion. All are rank 3 / base 5 RP; Action, V/S/F, raw Core range 60 feet and Instantaneous metadata. Speak with Dead preserves two actual source placements, Divination 3 and Necromancy 3, both M/F interpreted as F under the shared interface. Do not discard either school or grant either school's class list to everyone. Exact class access is in the attached records.

1. Eyes of the Divine — “See through magical and mundane disguises.” Decide whether this is one creature snapshot or a Self radius sense; source Instantaneous can support a bounded snapshot without automatically adding duration. Distinguish superficial visual illusion/costume from an actual shapechange: can it reveal the creature's true form as a private overlay while the physical form remains, or only an actual disguise used to impersonate? Do not invent hidden legal names, identity history, ancestry/class statistics or biological living gates. Define actual sight/perception, range, cover, Blindness, ordinary darkness and Invisible/Hidden interactions. Mundane disguise revelation must be useful without claiming every clothing choice/mask is malicious. Ordinary form changes, possession, Polymorph, disguise magic and innate alternate forms need explicit scope. True Sight (Lesser) already sees hidden/invisible creatures through non-solid obscurity but explicitly has no disguise/true-form package. This new spell's name does not import omniscient true sight. Actual information protection remains relevant; no automatic immunity pierce.

2. Future Echo — “Next round, choose initiative order for allies.” This is a consequential scheduler source, not permission to duplicate turns. Define when choices lock (cast resolution or next round boundary), allies/consent/self/number/range/line-of-effect eligibility, and what slots can be exchanged. A plausible bounded reading permutes the selected allies among their existing regular slots next numbered round while enemy/unselected slots remain. But confirm whether this adequately fulfills choosing order and whether the source instead permits choosing new positions. State duration/restoration after that single affected round, late entrants, absent/dead/incapacitated allies, reinforcements, simultaneous competing casts, replacement of pending schedules and any no-initiative casting disposition. Range is checked when choosing eligible allies; do not silently make distant no-longer-visible allies lose their already purchased order unless required.

Existing effects retain their original virtual start/end markers through initiative changes. New effects use the current schedule. An actual regular turn retains its normal Action/Bonus Action/movement and regular-start Reaction refresh, recharge/death-save/start effects; reordering itself must not create extra refreshes, periodic pulses, fall steps, recovery or uses. Existing fixed falling markers and absolute clocks cannot migrate or duplicate. Specify how next-round temporary slots return to baseline without double/missing regular turns. The full Time Loop runtime stays disabled and is not a prerequisite for authoring this bounded tabletop schedule; an unimplemented reorder adapter remains an honest runtime limitation.

3. Reveal Weakness — “Target's next saving throw is made with Disadvantage.” Raw resolution generic, no printed initial save. Choose one perceived creature 60 feet/LoE? Need a finite pending-rider duration instead of infinite Instantaneous status. No automatic extra save should be added to defend against the initial debuff unless an explicit NEW decision is justified. Is it the next actual save of any type, including concentration/death/sourced contests only if actually saves, or only a future caster spell? Preserve source's unqualified next saving throw if feasible. Consume before the roll even if disadvantage already exists or advantage cancels; no repeated application stack, no forced auto-failure, no success/outcome reversal. Original roll/replacement lineage remains same event for other rerolls. Protection from Scrying is information-only and should not automatically negate a noninformational roll modifier. No stat/weakness report unless source actually grants it.

4. Planar Window — “Open vision into another plane; detect native beings and effects.” Need actual destination: known plane alone, uniquely identified location there, corresponding location if planes possess an actual mapping, or some other rule? Avoid inventing universal coordinate correspondences. Is the source 60 feet local window placement, viewing radius on remote side, or both? Define a bounded useful private/public view, its size/duration/concentration, fixed point, lighting/Blindness, sound if any, who sees, LoE, remote target/projection barrier and actual interplanar/protective wards. Source grants vision and detection, not movement/portal/casting, full-plane census, target-plane ownership or arbitrary entity summoning. “Native beings and effects” needs an actual native/origin predicate and clear detectable presence/location/identity output; do not infer solely from species or alignment. Does it detect native creatures through ordinary Hidden/Invisible or merely label visible ones? If native status is undefined/protected, distinguish that from nonnative. A spell effect cast on a plane by a traveler is not automatically native in a cosmological sense unless the definition expressly makes it so. Include useful output when an unprotected native being is physically present but the setting lacks a software native-plane field.

5. Speak with Dead — two placements: “Ask 5 questions to a corpse” / “Corpse answers 5 questions.” Need real corpse/remains eligibility, ordinary dead Undead/Construct continuing-person cases versus inactive device wreck, and sufficient remnant without inventing a mandatory flesh tongue if the source does not require it. Do answers come from a retained memory echo or a freely willing soul? Source promises answers and does not say resurrection or willing identity; choose explicitly rather than importing another game's text. Define duration/concentration, who asks, timing/actions, audible vs private output/language, limited knowledge from the dead person's perspective, truthful/cooperative/hostile behavior, ambiguous/no-known answers, and exact five-question accounting. Compound questions must not silently grant unlimited answers. No post-death omniscience, skill download, forced resurrection/control or duplicate identity. Distinguish corporeal decay/body destruction, Soul Bind/resurrection-only blockers, memory/information protections, an already-living identity with old remains, active Undead creature vs actual corpse, and multiple body fragments/recasts. Source gives no ten-day/daily immunity; do not add one without discussion. A new paid cast may plausibly ask another five, while a duplicate fragment cannot become a different person's memories. Actual class school may matter for a Divination-specific ward: preserve Cleric/etc Divination and Crimson Agent/Druid/Thief Necromancy access instead of treating identity-school union as every cast's classification.

6. Faction Divination — “Learn a faction's current major objective.” Raw 60 feet cannot directly target an abstract institution without an interface. Need exact known factionId, geographic/planar scope if any, whether Self informational mode removes a physical anchor, and no invented positive standing/member/Seal gate. Define current major objective from actual institutional authority/established plans, not any member's private whim or Director's preferred plot. For multiple coequal objectives use one stable priority selection while unchanged rather than enumerating secrets via rephrasing. A genuinely different subfaction should require its own actual canonical identity, not invented subdivision loopholes. Unknown objective vs a faction genuinely having no current major objective, independent warded relevant facts and classified private individual objectives need distinct handling. Output should be a useful concrete goal, not necessarily full operations plan, member list, locations, timeline or secret actor identities. Hidden unprotected objective is valid information. Avoid making any protected leader erase every independently established institutional fact.

7. Alignment Revelation — “Force a creature to reveal their true alignment (CHA save negates).” Preserve source CHA save and rank-three price even though weaker lower-rank direct readings exist. Need define reveal: compulsory spoken declaration, public visible magic, or private caster information? A public magical disclosure may justify the different use without granting social control; decide rather than silently turning this into speech/mind control. Exact two canonical axes and unknown/protected fields, language/deafness/blindness, recipients/range/duration and masks are essential. “True” does not automatically break every actual protection unless explicit reviewed conflict says so. No oathbreaking/behavior/PvP/control/imposed alignment. A failed save should reveal actual values rather than compel a liar to speak an unverified statement. No automatically repeated immunity/daily cap absent source.

8. Resonance Sight (Greater) — “See all magical effects and their sources within 60 feet.” Distinguish source from origin location, actual creator identity, sustaining caster, item/zone producer and proximate responsible record. Which within-60 qualifier applies: visible effects and their possibly remote source identity, or both effects and sources must be locally in range? Preserve a useful upgrade over Resonance Map without inventing omniscient upstream conspiracy/remote current-location tracking. Does “see all” overcome non-solid obscurity/Invisible/Hidden magic only, or also solid cover? Need ordinary LoE, private/public/perception, instant snapshot vs NEW finite-duration sense. Does it identify the actual spell by name/rank or just presence/type/source link? RP pools are not inherently active effects under rank-zero/one reviewed distinctions. Active intrinsic magic, suppressed effects, copied effects, overlapping footprints, physical forms and permanent magic items need scope. Report actual established Director provenance when available, undefined/protected fields separately, do not transform old extinguished residue into an active effect. Current Resonance Tracking separately handles one-hour spell residues. Information protections must protect attached-magic subject information without blanking independent ambient magic. No dispel, charge/RP harvest, remote spell attack, new cast or recipe/statblock download.

All added targets, modes, durations, saves, detection rules and schedule interfaces must be labeled NEW. Retain each source conflict and meaningful overlap as an open balance/source issue rather than inventing an unreviewed buff or silently deleting a redundant identity.

32: 
33: The shared limit is one **extra full Action per creature per numbered round**. Such an Action cannot grant another extra Action, Bonus Action or Reaction. This cap is independent of Reaction timing. Extra turns do not by themselves refresh Reactions, recharge, periodic ticks, recovery ticks or the regular-turn allowances defined here.
34: 
35: **Reaction interpretation.** Begin an encounter with one available Reaction unless surprised or otherwise prohibited. Refresh at each regular own-turn start; never at the numbered round boundary or an extra turn. A late-initiative creature can therefore react before its first turn, refresh, and react again in the same numbered round. A legal trigger, available resource and all feature prerequisites are still required.
36: 
37: **Explicit additional Reactions.** A reviewed card can grant a separate limited use without refreshing the ordinary resource. Warrior Mind Shock supplies its stated once-per-duration non-attack Reaction; spending one resource does not consume/reset the other. Surprise, Incapacitated and Focused still restrict both. It grants no Counterspell knowledge or waived costs. Extra turns refresh neither. Per-dose reapplication/stacking and other specific grants remain part of the class semantic pass.
38: 
39: **Surprise — V6 plus NEW Bonus Action clarification.** On a surprised creature's first regular turn it cannot voluntarily move or take an Action or Bonus Action. It cannot react until that turn ends. Its slot, durations, passive effects, concentration, periodic effects and recharge still occur. Surprise alone is not Incapacitated or Unconscious. Brief communication and an otherwise legal simple free interaction remain possible.
40: 
41: **Entry — NEW.** Standard end-round reinforcements roll/receive initiative and first act next round. An explicit midround entrant acts this round only if its complete ordered slot is still upcoming; entry during that exact slot counts as already passed. It has its initial Reaction unless prohibited. A summon-specific timing rule overrides this generic entry procedure.
42: 
43: After the final slot, resolve Core's end-round hazards, reinforcements, morale, objectives and boss phases. Conclude the scene with surrender, capture, pursuit, harvesting access and noise consequences under their own rules; winning initiative does not resolve those automatically.

45: ## Time and event ordering — NEW
46: 
47: For a duration created in initiative, record the relevant original regular start/end marker. Existing effects keep that **virtual marker**, repeating every six seconds if the creature leaves or changes initiative. Reordering, rerolling, extra turns, death/removal or leaving/reentering initiative never restart an existing duration. New effects use the current schedule. Source death still ends concentration, a source-dependent aura/tether or an effect explicitly ending on death.
48: 
49: - A bare hostile target-bound **N rounds** ends at the Nth future regular target-end marker. An in-progress target turn's current end does not count.
50: - A bare self/source buff, ally-targeted buff or source-controlled aura **N rounds** ends at the Nth future source-start marker. Explicit target-turn, pulse or absolute timing overrides this default. Activation during source turn 1 for three rounds ends at source turn 4's start.
51: - **Next turn** means the next future regular turn of the named creature, not the current turn's still-upcoming end. An unqualified next turn refers to source/user under the existing shared rule. Explicit “this turn” can include the current turn.
52: - An outside-initiative bare N-round effect instead gets an absolute application-time + N×6 seconds deadline. Entering initiative preserves that deadline.
53: - Explicit periodic profiles retain their registered clocks and tick counts. Never create a second timer merely because a generic duration rule also exists.
54: 
55: The [exact GPT review](../../../../docs/audit/2026-10-08/full-game/GPT_COMBAT_EXACT_FINDINGS.md) confirms ally-buff source clocks and excluding the current turn for explicit next-turn endpoints. The helper excludes a specific current-end marker only if that marker would otherwise be selected: application during a turn at time1 with end3 excludes3 and selects9; application at/after3 also selects9, without erroneously skipping again to15.
56: 
57: At a regular turn's **start**, resolve in this order:
58: 
59: 1. Expire start-ending effects and apply immediate state changes from those expirations.
60: 2. Refresh Reaction; tick regular-start recharge/non-action clocks.
61: 3. Resolve already-due absolute state recovery if now legal, including a previously blocked Stable recovery deadline.
62: 4. If still alive, dying and at 0 HP with death saves, make that turn's death save.
63: 5. Resolve other start effects and periodic events in application order.
64: 6. Begin voluntary turn decisions.
65: 
66: At **end**, resolve triggered effects, due damage, saves and maintenance before end-ending effects expire; then the slot finishes. No extra turn creates another regular marker. The caller must not reuse a resolved marker.
67: 
68: For simultaneous effects, earlier application timestamp precedes later. For simultaneous components of one source, its printed internal order controls; otherwise use stable application sequence, with source/mechanical ID as a final tie-break. Record that sequence when creating the effects. Beneficial/harmful labels do not change priority. Periodic family arbitration happens once per family/marker before its damage, retaining the family registry's consumed loser ticks.
69: 
70: Examples: dying at 0 rolls its death save before ordinary start-turn healing; a fatal death save is not undone by ordinary healing. Stable at 0 skips the save, then start-turn damage can break Stable. A natural 20 can restore 1 HP before a due Bleed drops it to 0 as a new drop event. If Decay expires while a Stable recovery deadline is already due, the old deadline resolves once without rerolling recovery time.
