# Twelve Enchantment cantrips — source conference

The eight rank-three Divination cards are promoted exactly as submitted, without functional repairs. Fifteen promotion checks pass, including unchanged prior 190 cards and all nine original placements/Core blocks. Pipeline: 42 checks / 89,040 class-level access boundaries / zero issues. The catalog is now 198 reviewed identities / 650 unfinished, with 215 unfinished having some actual class rank 0–3. All 848 IDs and 936 placements remain. Divination, Conjuration and Abjuration have no unfinished identities with actual school rank 0–3, while unassigned variants, higher ranks, wider systems, runtime and human balance remain open. No GitHub push or source deletion.

Next is Enchantment. The low-rank source-only inventory contains 39 identities / 44 placements. Zone of Truth, Enthrall, Hypnotic Pattern, Fear and Slow have multiple placements; their future batches must preserve those conflicts. Enthrall's rank-two placement (Core349) has no current class-access grant and is explicitly registered as an unassigned source finding pending our conference. That does not affect today's twelve single-placement cantrips.

Please reconcile these twelve sources into complete draftable instructions, ideally below 17,000 characters. I will return exact authored cards before promotion. All are rank 0 / base 0 RP, with access at class1 for Bard, Crimson Agent, Mirrorsage, Thief and Wizard; Paladin at class2. All raw ranges are 30 feet and casting time Action. Most components are V/S; Faction Sympathy exceptionally prints V/S/M/F and concentration up to one minute, so preserve F and concentration rather than copying a generic cantrip template. Labels/tags alone grant no healing, movement, wards, Charm condition or control. Mark all added saves, duration, exact scope and action restrictions NEW.

1. False Comfort — “Target believes they are healing; no effect, distraction only.” Instantaneous. Preserve the explicit absence of actual healing. Does the source permit a fleeting subjective feeling of recovery with no numeric rider, or a bounded distraction bonus/penalty? Do not silently add HP, temporary HP, stabilization, Wound cure, healing triggers, removed pain conditions or a hard lost Action. Any involuntary belief/feeling save and finite duration should be NEW. Define what the target experiences without forcing an action or making the player ignore actual HP, damage, injuries or hazards. Creature type alone is not an assumed mind/illusion immunity.

2. Glimmering Eyes — “Caster gains +2 to Persuasion or Deception for 1 minute.” Preserve the flat +2. Self versus raw30 feet; choose one skill at casting or choose per check; all qualifying checks during the minute versus next check only; concentration absent. Strongest same-stat flat bonus rule applies. The visual name need not add an eye-contact prerequisite absent source, and the actual social task still needs its normal communication/context. This grants no compelled assent, truth, authority, friendship or altered reputation. One active application with a new skill choice should not bank both skills through cheap recasts unless explicitly intended.

3. Disrupt Memory — “Target forgets last 6 seconds; ends concentration.” Instantaneous. This is genuinely stronger than “loses focus”: preserve actual memory loss and ending concentration, while deciding a NEW save and exact target. Which six seconds—immediately before cast start or effect resolution? Is the memory removal permanent for that interval or a brief inability to recall? The source says forget, not time rewind. It must not undo damage, movement, paid costs, use histories, Dissonance/Refrain, observations retained by others, physical records or outcomes. Clarify learning the facts again from evidence, repeated casts affecting only their own six-second windows, and no recursive expansion into all prior memories. Ending real concentration must use the actual concentration source/end callbacks, not cancel every magical ability or source whose name says focus. If an exact class permits multiple maintained concentration records, determine scope explicitly. No automatic immunity to later casts absent source; no whole-Action denial from merely forgetting unless a separate rule actually causes one. Contrast with Enthralling Tune below.

4. Enthralling Tune — “Play a tone that draws attention; 1 target loses focus.” Instantaneous. Define a bounded useful attention effect and NEW save/window without equating the ambiguous word focus with automatic concentration loss; Disrupt Memory explicitly grants that. A hearing gate makes sense; a musical instrument requirement is not printed in V/S. Compare reviewed Lullaby's one-round Perception disadvantage and Calm Whispers' next attack disadvantage. Redundancy is preferable to inventing extra hard control just to distinguish names. No forced movement, compelled action, Dazed/Stunned or whole-turn loss merely from “enthralling.”

5. Mental Tap — “1d4 psychic; caster gains +1 to next save if damage dealt.” Instantaneous. Define exact save/attack and success result while preserving source1d4 and the conditional flat +1. The current numeric actualDamageDealt measure is tempHP absorbed plus actual normalHP lost, excluding overkill and later assignments; an HP floor may make that zero even for a positive packet. Please use or explicitly override that exact trigger rather than treating attempted damage/immunity as success. The beneficiary is caster. Define finite pending next-save endpoint, all actual save types or a bounded subset, consumption even when stronger flat bonus supersedes it, and no banking/stacks across repeat casts. Do not silently add enemy-only/non-boss/biological eligibility unless actual source evidence supports it. Damage and a later save buff do not refill RP or gain an extra Action.

6. Friends — “Gain advantage on Charisma checks against one non-hostile creature.” Instantaneous metadata needs a finite useful duration. Self benefit keyed to one creature versus a target condition, actual non-hostile relationship at application and whether later actual hostility ends it, no free preflight hostility oracle, and any save must be explicit. Preserve Charisma checks, not automatic success or general attacks/saves. Decide whether this imposes actual Charmed or only the printed advantage; the Core Charmed condition has an unwilling-to-harm restriction not printed here. Do not import another game's automatic post-expiry hostility or notification. Normal visible/audible casting and actual observer deductions still occur. One named target/application cap and concentration choice require a decision.

7. Soothe Animal — “Calm one beast or animal for 1 minute.” Define actual Beast/animal eligibility without importing a new creature-type change from a transformation profile name. Need a NEW save and what calm actually prevents/permits: lowered agitation, no unprovoked attack, suppression of a specific fear state, or another narrow procedure. Preserve useful calming without general domination, permanent taming, full-action denial, automatic loyalty, ownership or commands. Does existing combat/threat/damage break or prevent calm? Whose attacks count? Does it affect an explicit Frightened condition or just ordinary emotion? A target harmed during calm must retain a concrete defense/ending rule. Source has no concentration marker; don't add it silently.

8. Faction Sympathy — “Target briefly feels positive toward your faction.” Core explicitly says concentration up to1minute, V/S/M/F, generic resolution. Need actual “your faction” predicate: genuine current affiliation or any known faction you identify? Positive reputation alone is not membership under our other reviewed cards. Define involuntary save, emotional/attitude effect and any exact social bonus; no automatic membership, numeric reputation, institutional standing, credentials, rights, obedience or forced belief. This is not a license to import Movement/Ward effects from tags. End/refresh behavior and actual harm/hostility interactions need precision. Avoid both making “positive” meaningless and turning it into total loyalty.

9. Alignment Empathy — “Target briefly feels connection to your alignment.” Instantaneous. Define brief duration, save, useful subjective effect and whether actual caster axes are input at application. It should not silently change the target's canonical alignment, force behavior/oathbreaking/PvP, read either person's secret alignment, or grant alignment-gated weapons/wards/discounts. A feeling of connection need not disclose the numeric/canonical axes. Is it a mood-only effect, narrow social advantage/+1, or something else? Preserve real feeling without generic mind control. The Movement/Alignment tags create no movement.

10. Resonance Whisper — “Subtly influence target's next Resonance check.” Instantaneous. Use the already reviewed Resonance Mote bridge for an actual source-authorized Resonance/Weave task, not a fabricated universal casting/fizzle check. Decide exact helpful/harmful numeric adjustment, choice timing, willingness or save for harm, finite next-check window, stacking and consumption. The bridge excludes spell attacks, saves/concentration saves, Counterspell, ordinary casting, RP costs, Dissonance/Refrain and old Burn/fizzle. “Subtly” does not erase audible V or visible S components or automatically hide the caster.

11. Minor Suggestion — “Plant a simple, harmless idea in target's mind.” Instantaneous. Define exact mental/language communication, NEW save and what planting an idea does beyond an ordinary spoken proposal. Does it feel internally suggested while leaving choice intact, or cause one bounded harmless act? Do not silently promote it to the rank3 Suggestion source's eight-hour obedience. Define harmless from the target's actual known circumstances; a hidden hazard must not be manufactured safe by caster wording. No automatic self-harm, dispossession, hostile act, oath violation or disclosure of a secret absent the exact harmless-suggestion scope. No Charm condition, Action denial, permanent belief/memory replacement or truth verification merely from the name.

12. Beguiling Gaze — “Lock eyes with target; they can't look away for 1 round.” Preserve actual gaze lock rather than replacing it with an unrelated generic attack debuff. Need mutual sight/eye or analogous anatomy, NEW save, finite hostile first-future-target-end marker excluding an in-progress current target turn, and maintained range/sight/caster gaze/cover/Blindness endings. Core has no universal facing system: specify practical consequences without inventing a whole facing/field-of-view engine. Can the target still move, attack, cast or use peripheral awareness? Does it prevent voluntarily averting/closing eyes against an independently actual gaze effect? It must not itself grant a gaze attack, compel movement to follow the caster, freeze all Actions or auto-target someone across a wall. External loss of sight and actual defensive immunities keep their scope.

Shared reminders: each legal cast commits Action/components/RP/Dissonance/Refrain and counters normally; base0RP does not remove Refrain. V is audible/S needs the ordinary hand requirement. No automatic cantrip scaling. Save DC =8+PB+actual casting modifier; saves binary, no natural auto-success/failure. Hard whole-Action/turn denial uses the combined source-character/target/encounter cap, but do not label mere distraction/soft restrictions hard denial automatically. Explicit Charmed immunity blocks Charmed; it is not automatically immunity to every Enchantment-school effect. Written broader mental/enchantment defenses apply normally. The printed source can have an active Undead/Construct target unless its actual target predicate or applicable defense excludes it.

164: 
165: **Effect:** The creature cannot willingly take an action or make a choice it knows would harm the charmer: this includes attacks, harmful targeting, and knowingly placing the charmer in a harmful area or indirect effect. Unforeseeable or genuinely unknown collateral harm is not retroactively a willing violation. The charmer has advantage on social ability checks against it. Charmed itself never compels affection, obedience, beliefs, allegiance, affirmative protection or self-harm.

45: ## Time and event ordering — NEW
46: 
47: For a duration created in initiative, record the relevant original regular start/end marker. Existing effects keep that **virtual marker**, repeating every six seconds if the creature leaves or changes initiative. Reordering, rerolling, extra turns, death/removal or leaving/reentering initiative never restart an existing duration. New effects use the current schedule. Source death still ends concentration, a source-dependent aura/tether or an effect explicitly ending on death.
48: 
49: - A bare hostile target-bound **N rounds** ends at the Nth future regular target-end marker. An in-progress target turn's current end does not count.
50: - A bare self/source buff, ally-targeted buff or source-controlled aura **N rounds** ends at the Nth future source-start marker. Explicit target-turn, pulse or absolute timing overrides this default. Activation during source turn 1 for three rounds ends at source turn 4's start.
51: - **Next turn** means the next future regular turn of the named creature, not the current turn's still-upcoming end. An unqualified next turn refers to source/user under the existing shared rule. Explicit “this turn” can include the current turn.
52: - An outside-initiative bare N-round effect instead gets an absolute application-time + N×6 seconds deadline. Entering initiative preserves that deadline.
53: - Explicit periodic profiles retain their registered clocks and tick counts. Never create a second timer merely because a generic duration rule also exists.
54: 
55: The [exact GPT review](../../../../docs/audit/2026-10-08/full-game/GPT_COMBAT_EXACT_FINDINGS.md) confirms ally-buff source clocks and excluding the current turn for explicit next-turn endpoints. The helper excludes a specific current-end marker only if that marker would otherwise be selected: application during a turn at time1 with end3 excludes3 and selects9; application at/after3 also selects9, without erroneously skipping again to15.
56: 
57: At a regular turn's **start**, resolve in this order:
58: 
59: 1. Expire start-ending effects and apply immediate state changes from those expirations.
60: 2. Refresh Reaction; tick regular-start recharge/non-action clocks.
61: 3. Resolve already-due absolute state recovery if now legal, including a previously blocked Stable recovery deadline.
62: 4. If still alive, dying and at 0 HP with death saves, make that turn's death save.
63: 5. Resolve other start effects and periodic events in application order.
64: 6. Begin voluntary turn decisions.
65: 
66: At **end**, resolve triggered effects, due damage, saves and maintenance before end-ending effects expire; then the slot finishes. No extra turn creates another regular marker. The caller must not reuse a resolved marker.
67: 
68: For simultaneous effects, earlier application timestamp precedes later. For simultaneous components of one source, its printed internal order controls; otherwise use stable application sequence, with source/mechanical ID as a final tie-break. Record that sequence when creating the effects. Beneficial/harmful labels do not change priority. Periodic family arbitration happens once per family/marker before its damage, retaining the family registry's consumed loser ticks.

70: Examples: dying at 0 rolls its death save before ordinary start-turn healing; a fatal death save is not undone by ordinary healing. Stable at 0 skips the save, then start-turn damage can break Stable. A natural 20 can restore 1 HP before a due Bleed drops it to 0 as a new drop event. If Decay expires while a Stable recovery deadline is already due, the old deadline resolves once without rerolling recovery time.
