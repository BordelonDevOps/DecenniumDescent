1. Frost Nova — follow existing refresh policy

Use the existing CONTROL_STATES_PLAYTEST.md rule. Do not create a Frost-Nova-specific independent-copy exception.

Same owner / same target / same profile

A successful later Frost Nova from the same source owner against the same target uses:

same-owner / same-target / same-group / exact-profile refresh

The Speed-0 component remains one source-owned record. Its deadline becomes the later of:

its existing unexpired deadline; or
the new successful application's ordinary Frost Nova deadline.

It never:

adds magnitude below Speed 0;
shortens the existing deadline;
creates another parallel same-owner Speed-0 record;
refunds/recreates any spent control history.

Each paid Frost Nova cast still resolves its 2d8 cold damage independently. Only the identical Speed-0 rider uses refresh semantics.

A saved-against/prevented new Speed-0 application does not refresh the old record.

Different owners

Different source owners retain independent Speed-0 records and deadlines.

Removing/expiring one exposes any other valid record normally.

Classification

NEW explicit classification:

Frost Nova's rider is:

source-owned magical elemental Speed control: Speed 0

While active and unsuppressed, it qualifies for eligibility.slowed-foe.

It is not:

Core Frozen;
Restrained;
Incapacitated;
Root unless some other rule expressly classifies it that way.

Therefore:

a Frozen-only cure does not remove it;
a Restrained-only cure does not remove it;
generic condition removal that does not actually encompass unnamed/source-owned magical movement restrictions does not remove it;
an effect that expressly removes/suppresses Speed 0, magical movement restriction, or this source's movement component can affect it according to that effect's scope.

The word “freeze” in the original prose does not silently apply the full Frozen condition.

Balanced Elements

Approve Frost Nova as an individually reviewed elemental Speed-control component for the existing Balanced Elements bridge.

Use the existing extension formula unchanged:

max(existingDeadline, targetFollowingRegularEndMeasuredNow)

with the existing rules that it:

excludes the current in-progress target END;
does not recursively add another round onto the old deadline;
does not increase magnitude;
does not revive an ended/prevented effect;
extends only this Speed-control component, not the 2d8 damage or another component;
remains bounded by any actual express governing source/concentration maximum.
Is Frost Nova's nominal one-round endpoint a hard maximum?

No.

For Frost Nova, the first-future-regular-END / +6-second endpoint is the base application deadline, not an anti-extension hard cap.

Balanced Elements is the explicit reviewed rule authorized to extend that elemental Speed-control record beyond its nominal Frost Nova endpoint.

This does not mean Frost Nova can extend itself by recursing its own old deadline. Same-owner Frost Nova reapplication uses the ordinary refresh rule above; Balanced Elements uses its own reviewed extension formula.

If a future source supplies an actual explicit maximum that says the component cannot persist beyond a stated cap, Balanced Elements obeys that cap.

2. Shatter — fixed pre-damage snapshot and structural sections

Approve the proposed pre-damage snapshot with one additional deterministic section-selection rule.

NEW — initial snapshot

After the cast survives interruption, but before any Shatter damage resolves, establish one fixed snapshot of:

all eligible creatures in the 10-ft sphere with center LoE;
all eligible ordinary nonmagical discrete objects in the sphere with center LoE;
each actual distinct large structure/terrain feature intersecting the sphere and having an exposed LoE-reachable portion inside it.

Damage from the spell cannot expose a second target, remove cover to add another target, or cause the spell to rescan the area.

No re-selection after packets begin resolving.

Ordinary objects

The object categories remain:

unattended ordinary nonmagical objects;
caster-held ordinary nonmagical objects;
ordinary nonmagical objects deliberately offered/exposed by willing holders.

No hostile worn/carried equipment is automatically included.

Each eligible discrete object receives one grouped:

shared 3d8 base + shared 1d8 object bonus

thunder packet.

Creatures never receive the extra 1d8.

Large structures / terrain

Treat each actual structural whole as one structure, not as arbitrary named panels, bricks, wall segments, floorboards, etc. that could multiply packets.

For each distinct large structure/terrain feature, affect at most:

one contiguous exposed section wholly within the original 10-ft sphere and bounded by a 5-ft cube.

No part outside the sphere receives damage.

Who selects the section?

Because Shatter is an automatic area effect rather than a targeted structural attack, use a neutral geometry rule rather than caster selection:

For each distinct large structure/terrain feature, use the eligible exposed section containing the LoE-reachable point of that structure nearest the spell's center, bounded to one contiguous 5-ft-cube section. If equivalent points tie, the Director resolves the tie by stable neutral geometry/order, never by choosing after damage outcomes.

This avoids:

a hidden-structure identification oracle;
caster cherry-picking a concealed load-bearing element;
Director after-the-fact outcome optimization.

The Director determines the actual real structural identity and hidden boundaries without disclosing hidden information merely because Shatter was cast.

Large discrete objects

A genuinely separate freestanding large object remains its own object.

If it exceeds the bounded damage scale used by actual object/structure rules, damage only the legal affected section; do not transfer that one section's damage automatically through the whole object.

Structural aftermath

Fix every section before any damage resolves.

After damage:

actual object durability applies;
actual collapse/support/falling rules may follow;
Shatter itself does not guarantee whole-building collapse, propagation, rubble generation, or secondary structural damage beyond those real consequences.

This makes the structural procedure deterministic and non-recursive.

3. Acid Arrow — bounded hit and delayed recipient

Confirm all proposed completions.

Initial attack and attachment order

Use this exact sequence:

legally resolve the ranged spell attack;
miss → no initial damage and no delayed rider;
hit → resolve the initial 4d4 acid packet;
after that packet finishes, if the same recipient still exists as the same continuing eligible entity, establish the delayed 2d4 source-owned rider.

Therefore:

initial acid reduced to 0 does not itself prevent attachment;
an actual defense specifically preventing the magical rider can;
if the initial packet destroys an object or actually ends the creature's continuing identity before attachment, no delayed rider is created.

Merely reducing a creature to 0 HP does not automatically defeat attachment if that creature still exists as the same continuing creature under the death-state rules.

No corpse/replacement/new-creature rider is created.

Critical damage

Confirmed:

critical doubles only the initial attack's 4d4 attack damage dice;
delayed 2d4 never doubles;
delayed event is not an attack.
Delayed event ownership

Each successful hit establishes one independent source-owned delayed event.

It is:

not another spell cast;
no RP;
no Dissonance;
no Refrain;
no cast-begin hooks;
no Counterspell window;
one separate damage packet when it executes.

Same-caster and different-caster riders may coexist exactly as previously ruled.

Schedule preservation

Preserve the originally established execution marker:

Creature recipient

first future target regular END, excluding current target turn.

Object recipient

first future caster regular END, excluding current caster turn.

Outside initiative

application +6 seconds.

Initiative entry/exit/reorder, caster absence, target absence, plane change, or extra turns do not manufacture a new deadline.

Use the original corresponding regular/virtual marker.

Extra turns never accelerate the pulse.

Removal and suppression

The pending delayed rider is an ongoing source-owned rank-2 spell effect until it:

executes;
is actually removed;
loses its continuing recipient;
otherwise ends under an applicable rule.

An eligible dispel can remove that specific rider before execution.

Suppression does not pause or move its marker.

If it remains suppressed when the scheduled event arrives:

no 2d4 occurs;
that one-shot event is consumed;
the rider ends;
lifting suppression later does not replay it.
Continuing identity

The delayed rider follows the same continuing recipient, not merely a coordinate or corpse.

Thus:

ordinary movement does not lose it;
range/LoE/perception loss does not lose it;
caster absence does not lose it;
a transformation preserving the same creature identity normally preserves it unless that transformation's rules expressly end/suppress the spell.

Actual death/ended creature identity, destruction of an object, replacement/resummoning, etc. ends that recipient's rider.

No later resurrection/recreation inherits it.

No washing/scraping action or persistent mundane acid substance is invented.
