Internal preparation for a later GPT conference. No case below is a rule or approval. Preserve all 44 formulas (160–199,640–643), with 28 public / three restricted / thirteen Director-only. [Full sources and book bindings](FISHING_SOURCE_PREPARATION.json) retain the exact fishing bonuses, extra units and attraction text.

The reviewed trade reference already classifies Fishing tackle as a particular **non-artisan** tool proficiency and gives Fishing WIS. The crafting framework permits Fishing for compatible aquatic harvesting; it does not thereby supply a complete catching procedure. Honor those existing boundaries. Any proposed exception must be explicit. The shared six-band crafting check, normal harvest checks, fishing attempts and combat remain distinct procedures.
