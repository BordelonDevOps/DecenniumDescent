# Numeric feat prerequisite boundary evidence

**Finite source-qualified synthetic projections; exact candidate remains unapproved.**

This pass covers all 209 numeric/level/None prerequisite trees, representing 62 exact printed forms. It executes 1678 boundary cases against an independent parser of the original printed prerequisite strings. 416 distinct synthetic ability/class-history projections support those cases. 11846 checks completed with 0 failures.

Each projection uses possible four-d6/drop-lowest results, Human plus the actual Imperial Human variant bonuses once, and attained Bard class levels. Earlier ASI choices are recorded as distinct Alert, Alertness or Lucky grants where needed; these do not increase permanent abilities. No example purports to record actual human rolls or a real campaign award. These are prerequisite projections, not complete character sheets.

The full boundary grid includes one below, exactly at and one above every ability/level threshold; each OR arm can qualify alone. Temporary scene bonuses are excluded from permanent scores. A correct numeric predicate still needs an earned unspent class opportunity. Missing, spent, renamed and unearned opportunities fail. All 17 actual class ASI schedules are checked, including Oracle 4/8/14/19. Bard 3 / Mage 1 meets total level 4 but has earned neither class's level-4 ASI.

A passing result does **not** prove a complete feat acquisition: any named curriculum, spell, armor, save, ASI allocation, nonrepeatable identity, target, finite initialization or deferred payload still needs its own source-qualified check. None means no printed prerequisite; it does not grant a free choice or make Astral Projection/Planar Binding payloads available. Candidate selection remains disabled, and no operative source or candidate was changed.
