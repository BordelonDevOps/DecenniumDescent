# Decennium Descent — Abjuration/Conjuration Rank-4 Cohort

**Status:** NEW provisional authored playtest reference candidate. These are operative table procedures for the fifteen requested cards only. They do not approve Banishment, canon, balance, runtime or later spell cohorts.

## Shared casting procedure
Use SPELL_INTEGRATION_RULES.md exactly: legal action/components/target/repertoire first; class-specific rank/cost; pre-cast Dissonance; commit RP/materials/concentration; apply Dissonance/Refrain/cast-begin hooks; resolve interruption; then effect. Failed/countered/saved casts refund nothing.

**Time.** One-minute concentration effects use the source's normal ten future caster regular-start markers in initiative or 60 elapsed seconds outside unless this card states a different exact clock. Spell Shield is nonconcentration but uses its own fixed tenth-future-caster-start / application+60s deadline; caster death alone does not end it. Ten minutes = 100 future caster regular-start markers or 600 elapsed seconds. Alignment Lock uses 24 elapsed hours; rank-7 Alignment Anchor uses seven elapsed days; Bind Element uses two future target regular ends / 12 elapsed seconds outside initiative. Preserve virtual/absolute deadlines through initiative changes, absence and suppression.

**Faction records.** Use standing-v1 separately from membership and invocation permission. Faction Seal's reviewed invocation-permission procedure is the permission reference where invoked. Positive standing never creates membership or permission.

**Alignment overlays.** Reviewed Alignment Purge AP-AS-01 remains exactly source-specific. AC4-ALIGN-01 is an additional NEW scoped exception only for Alignment Lock/Alignment Anchor; it creates no universal alignment priority engine.

**Null.** Damage-root identity remains governed by accepted EPI-08–14. Pure redirection does not itself create a new root or advance the original root checkpoint. If the original spell has not created its root yet, evaluate the original caster/dealer's Veil state only when that root is actually created. New reflected/retaliatory damage uses a new root only when an exact effect says it creates one. Finite summons reduced to 0 by qualifying Null damage use the accepted Disabled branch while independent expiry/concentration/replacement remains real.

CURRENT INTERFACE — Spell Shield is pure redirection of the already-pending original spell payload. The original cast ID, generating rank, caster ownership, attack/save statistics, concentration owner and source costs remain unchanged. If the returned spell creates an ongoing target branch or delayed rider, that branch/rider is attached to the original caster as its new recipient while retaining the original spell/caster identity. Reflection itself creates no root. A Veiled reflector therefore supplies no Null flag merely by reflecting, and the reflector's later Veil changes are irrelevant to the original spell's dealer checkpoint. Non-damaging spells such as Charm Person create no damage root at all. The packet cannot trigger Spell Shield again and cannot be copied/reflected recursively.

CURRENT INTERFACE — NEW scoped exception `AC4-ALIGN-01` for Alignment Lock/Alignment Anchor versus reviewed Alignment Purge/Suggestion. When Lock/Anchor ends or is inactive because a zone was exited/suppressed, the then-live lower lawful result becomes effective immediately with its original deadline/history; no old snapshot is restored and no missed application replays. Undefined axes are never fabricated.
