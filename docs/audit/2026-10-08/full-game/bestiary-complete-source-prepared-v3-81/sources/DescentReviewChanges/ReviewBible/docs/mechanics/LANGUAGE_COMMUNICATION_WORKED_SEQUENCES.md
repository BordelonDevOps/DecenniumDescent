# Worked language and communication sequences

**Reviewed authored language/communication playtest v1.1.** These are hypothetical authored adjudications, not gameplay-software tests or human playtest results. Follow the [language chapter](LANGUAGE_COMMUNICATION_PLAYTEST.md) and each actual feature card.

## LA-T01 — Grant boundaries

1. Record Common and Giant from the actual trait.
2. Do not add Trollish.
3. A separate lawful choice/course could grant Trollish later.

**Outcome:** Two fixed competencies, unchanged source spelling; Mycelian remains a regional choice and Deep Dwarf does not gain Murkish.
