# Final four crafting trades — unresolved decision cases

Internal preparation only. These50 cases ask for source/interface decisions; no outcome, new power, replacement value, item classification or cosmological interpretation is adopted here. Read alongside all167 full sources,100 actual public-book bindings, the preserved source differences and then-current reviewed guides. Exact authored-card review must follow the source conference.
