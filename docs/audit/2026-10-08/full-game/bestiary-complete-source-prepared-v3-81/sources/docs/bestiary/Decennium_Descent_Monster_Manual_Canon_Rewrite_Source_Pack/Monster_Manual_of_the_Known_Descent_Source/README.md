# Monster Manual of the Known Descent

**Authoritative volume** inside the Canon Rewrite Source Pack (see parent [`../README.md`](../README.md)).

This is the player-facing and ordinary table-reference bestiary. It represents what Aethel can know through Haven scholarship, expedition reports, and recognized history. It intentionally stops at the failed Sixth Gate record.

The book does not name or describe Tiers VII-X, the Marquis of Silence, the claimant phase, the true terminal expedition, Floor 97/100 crystal path, or Old God vulnerability. See `CANON_BOUNDARY.md`.
