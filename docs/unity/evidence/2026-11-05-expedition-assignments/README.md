# Schema39 expedition assignment checkpoint

Schema39 persists an explicit work assignment over the existing shared-clock traversal and procedure records. The worker follows player-directed local steps to the site; arrival marks the assignment Ready; a separate command starts the existing tool-repair or physical Trap-retrieval handler and records its job ID.

This remains TEST_ONLY. Assignment itself has no clock, action, reservation, material, proficiency or custody effects. Repair and retrieval retain their own admission checks and work ledgers. See the [decision record](../../EXPEDITION_ASSIGNMENT_RULE_DECISIONS.md).
