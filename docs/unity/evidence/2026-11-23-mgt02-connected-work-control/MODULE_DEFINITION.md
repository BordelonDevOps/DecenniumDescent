## Result for the player

The connected C# session will let a controlled character start, inspect, pause and resume the existing water-filling, exposed-node mining, recipe-4 research and recipe-4 manufacturing procedures, and cancel where the native procedure permits it. The console will expose the same commands, explanations and exact resource/work state. Existing quality choices remain explicit player decisions.

This connects existing rules to ordinary play; it adds no recipe, resource replenishment, scheduler, clock, RNG, actor, new work outcome or Unity integration. In particular, mining has **no cancellation command**. Manufacturing cancellation permanently closes the selected one-order batch, so cancellation and useful-product witnesses must be separate branches.
