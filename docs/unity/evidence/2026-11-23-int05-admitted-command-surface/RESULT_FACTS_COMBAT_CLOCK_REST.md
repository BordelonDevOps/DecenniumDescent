# Proposed result fields: combat, clock and rest

This is the first bounded HC-D6 field matrix, derived from actual native records and the separate review by `/root/review_consecration`. It does not cover all 78 operations, authorize implementation or claim a runtime test. Work, inventory, acquisition, care, magic, advancement and host-control fields still need their own exact rows. Common attempt facts apply to every submission; later historical facts require native retention.

All record paths below are under `engine/com.decennium.foundation/Runtime/Core/` unless a Model path is stated. Line locators refer to the unchanged runtime at `c807ada65`. Availability is field-specific and can become Withheld under current access. No raw record serialization is authorized.

## Proposed current-disclosure predicates

- **A — current command access:** the exact endpoint binds its actual principal and current enabled seat/trusted grant; actor control and native inventory claims pass, with only the existing exact transaction exceptions. A stale command's original ExpectedRevision is not rewritten. This permits matching the principal's exact receipt, not unrestricted target/record disclosure.
- **O — own character information:** A plus current control of the character and the existing native character-observation permission through this authorized view route. Operator-only ClockGrant does not satisfy O even though it controls Hero for clock commands. A trusted defender grant is not party observation authority. Observing an opponent's position does not satisfy O for its HP, defenses, saves or private effects.
- **V — visible action participant:** A plus the command actor's currently permitted observation of the relevant participant through the existing ObservationRules/native view. V permits the bounded public action/movement outcome defined in the row, not target AC, private HP, save DC, hidden source IDs or random state.
- **I — inventory information:** A plus the native current inventory-owner/access predicate for each lot/vessel being described. Actor control alone is insufficient.
- **C — clock-only operator facts:** matching SessionPrincipal and its exact existing clock/closure grant; disclose its receipt and applicable clock/continuation status. C does not imply O, V or I. A current pending participant/decision identity needs its own disclosure right.

These are proposed conjunctions of existing authority/observation semantics. The final matrix must bind each new field to a concrete predicate implementation and redaction test; these labels do not themselves grant authority.

Where a field is irrelevant to the operation or no authoritative command was executed, use NotApplicable. Where access is absent, use Withheld without asserting a private record's existence. A result's disclosure predicate is re-evaluated after restore, revocation and changed visibility. Required immediate results cannot be replaced with a blanket NotRetained response.

This matrix preserves native record semantics; it does not amend source rules or close HC-D6. Remaining families, exact DTO field keys, concrete projection methods, transitive pure accessors and executable witnesses remain open.
