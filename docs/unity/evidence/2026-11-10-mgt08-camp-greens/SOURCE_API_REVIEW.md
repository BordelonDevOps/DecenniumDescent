## Actual GPT source/API disposition

[Unity Rules Engine Development](https://chatgpt.com/c/6af31754-d1bc-83ea-aa5c-d5e33cc9258c) agreed that first active work means the first positive amount of credited labor. GPT approved an opt-in TEST_ONLY behavior profile with a distinct content fingerprint using each host's existing schema and codecs. All historical profiles retain their admission-time debit. Use the existing `CropWorkRecord` and `WorkLedger` reservation, including fractional first labor and inventory operations that advance the same clock. The reviewer inspected the pinned source and existing implementation paths without changing code or executing tests. Codex agrees to the bounded contract below.

| Boundary | Approved behavior |
| --- | --- |
| Assignment and travel | No crop task, claim or water debit until the existing start command succeeds. |
| Admission and zero-progress pause | Reserve eight pints, with no change to physical stock or care. Pause retains the claim and task identity, removes future labor, and gives no progress or debit while paused. |
| Resume and first work | Same worker, task and claim. Any positive exact labor settles all eight pints once. Later pause and resume retain consumption. |
| Completion and termination | Renew care at 900 active seconds. Terminal zero-progress work releases the unspent claim. Terminal positive-progress work keeps the debit. Credit eligible labor before resolving its endpoint. |
| Validation | Working/paused zero progress must be reserved in full. Positive progress must be consumed in full. Cancelled zero progress must be released in full. Compute physical stock using actual consumption. Reject missing, mismatched or mixed claims. |
| Compatibility | Keep schemas, command fingerprints and old behavior fingerprints. Bind the opt-in to final content identity and reject cross-profile restore. Preserve normal replay, planting, crop quantities, deadlines and assignment cancellation. |
