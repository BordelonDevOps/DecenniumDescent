# GPT consensus: untrained generic harvest and accident type

**Chat:** Unity Rules Engine Development  
**Date:** 2026-11-05  
**Decision needed:** whether generic harvesting is blocked without proficiency, and whether the Fishing fallback accident has a typed damage rule.

GPT read the pinned playtest text and concluded:

1. Allow a physically possible untrained generic harvest. Use the trade's ability, contribute zero proficiency, and apply untrained disadvantage. Actual tools, physical access, custody, and restricted-material authorization remain required. A missing numerical trade rank is not a prohibition.
2. A trained lead adds the qualifying recorded proficiency contribution once. Any explicit applicable expertise replaces the ordinary contribution rather than stacking a second PB.
3. Generic extraction does not use identification's knowledge-skill gate as an extraction proficiency gate.
4. The Fishing fallback accident is `1d4` piercing. The harvest playtest supplies the `1d4` fallback; the pinned trade reference assigns piercing to Fishing's injury. Resolve an actually declared hazard instead, and do not also roll a manufacturing mishap.
5. Neither interpretation requires owner escalation.
