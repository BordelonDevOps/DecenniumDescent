# Class playtest — legal build examples

[Class library](CLASS_PLAYTEST_INDEX.md) · [Shared rules](CLASS_PLAYTEST_RULES.md) · [Validation data](CLASS_PLAYTEST_VALIDATION.json)

These are legal acquisition examples, not recommendations or claims of optimal balance. Each ordinary table was produced by the validator from eligible cards. Add the automatic grants, equipment, ability scores and spells stated in its class guide. ASI/feat milestones are separate. No later-stage ability is available to a level-1 Base character.

Bard retains its original [complete worked build and card packet](BARD_PLAYTEST_v0_1.md).
