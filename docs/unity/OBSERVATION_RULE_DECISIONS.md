# Observation, Hide and Search — implementation contract

**Status:** Codex/GPT implementation consensus for a TEST_ONLY C# increment; not release approval or a claim that all sensory rules are settled.

## Responsibilities and authoritative records

This module supplies one shared planar observation query to exploration and tactical combat. It keeps **direct sight**, **line of effect**, **current-location knowledge**, **last-known position**, **Hidden state**, and the per-observer Invisible revelation latch separate. It admits only tactical Hide and Search commands; it does not add exploration action durations.

Existing `ActorState` positions and `WorldTraversalRecord` partial distance remain authoritative for location. `ConditionJournal` remains authoritative for active, suppressed and expired Invisible applications. `ActorCharacterRecord`, `SkillTrainingRecord`, `ActorLifeRecord`, the shared RNG, tactical Action interval, command receipts and `RuleClock` remain authoritative for ability modifiers, injury, dice, cost, replay and time. New schema51 records own only observation actions/results and per-observer knowledge. Map cells and actor sight/search profiles are immutable, fingerprinted TEST_ONLY fixture content.

## Adopted operational policy and limits

1. The map is a discrete, authored planar grid. Actor anchors are cell centers. Exact rational partial edge position is used while traversing. A deterministic supercover/closed-cell-intersection query treats corner touch as blocked. Sight, effect and movement blockers are separate channels. With no explicit surface/interior-anchor model, actors, objects and traversal endpoints cannot occupy cells blocking any of those channels; a blocker remains an independent channel fact and is not automatically made solid. Cover is separately authored; no cover is inferred from an arbitrary obstacle.
2. Every admitted observer has an explicitly authored maximum direct-sight range. The TEST_ONLY fixture also supplies any candidate-search reach it uses. There is no default/universal radius, light model, hearing radius, smell model, special-sense framework or automatic sound propagation. Geometry alone never establishes hearing.
3. A Search names a candidate grid cell, not an actor ID. A successful WIS/Perception task reveals current location only to the searching actor and ends Hidden only for that observer. It grants no sight and propagates no knowledge. Multiple hidden targets in one candidate cell reject as ambiguous. INT/Investigation requires a separately authored trace, DC and outcome; it is not substituted for direct-location Perception.
4. Hide rolls DEX/Stealth once and compares the same result with each eligible observer's passive Perception DC. Eligibility is computed before applying Hidden. Core task degrees and natural shifts are retained; no passive ±5 shortcut is added. A failed unchanged attempt cannot be rerolled. Changed position or observation circumstances permit, but do not require, another attempt; history is retained.
5. Per-observer current-location knowledge survives ordinary loss of sight while the target remains at the disclosed position. Unobserved relocation invalidates current knowledge and preserves the last-known coordinate. A successful Hide invalidates current knowledge for that observer. Direct sight or supported location disclosure removes Hidden for that observer.
6. The Invisible latch is keyed to the earliest application in the currently connected interval union of operative Invisible applications. A disclosure latches that episode. Losing sight, moving unseen, or invalidating current-location knowledge does not reset it. A genuinely new episode uses a new key.
7. Tactical movement evaluates the actual traversed segment, including exact partial edge position and visibility intervals, whether the observer or target moves. Interval midpoints classify visibility only; they are not stored as sightings. If a visible interval ends at a closed, blocked boundary, persist that exact excluded position/time as `DirectSightLimit` and clear Hidden because actual exposure occurred inside the interval. Current-location knowledge is false when the target moved beyond the limit; it remains true when only the observer moved and the target stayed at its disclosed location. In both cases the boundary itself is not visible or targetable. Search and Hide are tactical Actions in this increment. No general exploration Search duration is added.
8. Attack checks consume current observer knowledge and distinct sight/effect channels. They resolve from pre-attack knowledge. Post-attack disclosure is recorded only for observers for whom the admitted attack supplies directly perceivable visual evidence; this does not infer hearing through geometry. A directly selected target with unknown current location is illegal; a separately authored suspected-space attack remains a distinct source procedure.

## 2026-11-06 — exact path visibility and historical profile replay (Codex/GPT consensus; schema51 unchanged)

The prior midpoint-based path recorded an arbitrary sample as the last sighting. Splitting the same traversal across `AdvanceClock` calls changed the stored coordinate and time even when the actor followed the same edge for the same total duration. Codex and GPT agreed this violated the observation contract: clock-command partitioning is an execution detail, and interval midpoints may classify visibility but are not sighting events.

For either moving actor, `ObservationRules.RecordPathSight` checks exact visibility breakpoints and one interior point per stable interval. A visible interval ending at a blocked boundary records the exact excluded limit and its time; the preceding real exposure clears Hidden only for that observer. When the target moved, the record is stale and `CurrentLocationKnown=false`. When the observer moved around a stationary target, the record keeps `CurrentLocationKnown=true` because the target did not relocate. `ObservationGeometry.CanSee` rejects the closed boundary. `DirectSightLimit` reports where visibility ended; it does not itself authorize sight-dependent targeting.

`DirectSightLimit` is appended as enum value `4`; existing numeric values remain `None=0`, `DirectSight=1`, `Search=2`, and `AttackEvidence=3`. The existing integer field is reused, so schema51's serialized layout and older enum values are unchanged. The content fingerprint now distinguishes `LegacySampledV1` from `ExactPathIntervalsV2`; exact intervals are the default, and the explicit legacy profile retains the original fingerprint and algorithm for existing schema51 histories. A save generated by pushed commit `a2701c20a28e642c6f2d920982211b1426875e5c` restores and replays byte-for-byte with the legacy profile; the exact profile rejects it through the existing fingerprint check instead of silently replaying it under changed rules. This is explicit profile compatibility, not a save migration.

## Implemented acceptance (schema51, bounded TEST_ONLY)

`observation_shared_hide_search_save_replay_and_observer_isolation` runs the connected shared-world host on one authored 8×8 TEST_ONLY map with two opaque cells. It rejects an unknown-location direct attack and out-of-range Search atomically, performs one Hide roll against two observers and verifies separate observer rows, saves/restores those outcomes, lets one observer Search the candidate cell and confirms the other remains Hidden and uninformed, validates a malformed persisted Search bound, checks save round-trip and deterministic whole-trace replay. `observation_attack_rejects_known_target_through_effect_blocker` uses a transparent effect-only barrier: the target remains visible and its location is known, while the attack is rejected as `BlockedLineOfEffect` with byte-identical state, combat history and observer knowledge. `observation_map_rejects_unsupported_anchor_placement` rejects restored actor/object placements in opaque blockers, effect-only and sight-only placements, and a traversal endpoint in a movement blocker. It also verifies a transparent effect-only barrier preserves sight while blocking line of effect, and that a corner-touching sight trace blocks symmetrically while effect remains clear. `observation_shared_world_traversal_records_partial_sighting_before_concealed_endpoint` runs shared-world movement through a sight gap, saves and restores at an exact partial position, and retains the exact closed sight-loss limit as stale `DirectSightLimit` evidence; replay from identical initial bytes yields identical final bytes. `observation_partial_exposure_clears_hidden_only_for_the_observer_who_sees` establishes Hidden through the actual shared-world BeginEncounter and Hide commands, then invokes the same `ProcessWorldTraversalSegments` processor used by shared movement with an exact 0-to-1.25-foot segment. It verifies that the companion's brief direct sight clears only that observer's Hidden attempt, the occluded second observer remains Hidden, the exact current location is saved, snapshot bytes round-trip, a repeat from identical Hide-state bytes produces identical output, and clock/RNG/revision/receipts do not change. `observation_tactical_hide_survives_exit_then_legal_exploration_sighting_is_observer_specific` joins these pieces with legal commands: after world approach and tactical Hide against both observers, it saves/restores, legally moves a blinded TEST_ONLY opponent to melee range, resolves combat and exits, then continues exploration through partial traversal. The companion alone sees the hider during an exposed interval and loses its Hidden latch. Whole-edge, mid-edge save/restore, and exact visibility-entry-boundary save/restore traces end with the same excluded `DirectSightLimit` coordinate/time; the boundary itself fails sight, an interior point on the visible side passes, and the other observer's knowledge is unchanged. Replaying from identical encounter bytes produces identical final snapshot bytes. This is bounded TEST_ONLY geometry and combat content; it adds no command or snapshot field.

`observation_invisible_latches_location_known_before_episode` covers the pinned Invisible case where the observer already has current location knowledge before the condition begins. The shared encounter and condition commands apply Invisible; direct sight stops, the current location remains known, and that observer's `RevealedInvisibleEpisodeId` latches to the active continuous episode. The test saves/restores, advances the target one legal unseen tactical step, verifies current-location knowledge expires while the old coordinate and same-episode latch remain, saves/restores again, and replays the initial command trace byte-for-byte. This fixes a transition omission in `ObservationRules.Refresh` without changing saved schema or condition authority. The legal step uses the existing tactical movement command and its ordinary Action/movement records.

The public tactical Search query is deliberately separate from Search resolution. It checks the shared Action prerequisites, target turn, candidate bounds and authored range without reading Hidden targets, actor identities at that location or the Hide total. `Simulation.DiscoverCommands` lists all in-range authored cells in stable row-major order independent of hidden occupancy. `Available` means the actor may spend an Action searching that cell; the existing resolver still records a no-finding or resolves the existing Search check. The focused acceptance compares a hidden-occupied cell with an empty in-range cell, confirms equal Action cost and byte-identical state after query/discovery, then exercises the existing successful Search, observer-specific location disclosure, save/restore and replay. This adds no schema or exploration-time cost. Hide still requires its own query assessment when that surface is implemented.

The new route acceptance revisits two separate visibility windows with opaque cells between them; blocked continuations preserve prior evidence, and later real exposure replaces it. Clock splitting and snapshot restore at the exact sight-loss boundary preserve the complete observer-knowledge set, apart from evidence revision provenance, which correctly follows the command history. These cases do not establish the complete module acceptance. Other Invisible episode edges (including expiry/new-episode behavior and overlapping applications), successful AttackEvidence disclosure, reaction/Overwatch interaction, exploration Hide/Search costs, and a second independently authored command-trace layout remain open. ## Unresolved work

General sensory and lighting rules; production geometry/content authoring; vertical/3D sight; hearing or sound evidence; feature-granted senses and Hide permissions; authored Investigation tasks; broad hidden-object discovery; general suspected-space attacks; other Invisible episode edges; attack-evidence and reaction/Overwatch acceptance; exploration Hide/Search costs; and owner/release decisions remain outside this increment. The pinned attack rule makes disclosure conditional on an observer perceiving attack evidence. This fixture has direct sight but no sound, projectile-trail or other event-sensory channel; a valid Hidden state also cannot coexist with the direct sight query. The visual-only consensus therefore does not identify an eligible post-attack evidence channel for a hidden attacker. Do not manufacture hearing from geometry or claim attack disclosure complete until a supported evidence channel is defined. Missing geometry/profile data fails closed. Fixture values are test facts, not recovered Decennium numbers.
